# 좀비 샷

탄약을 골라 탄창에 배치하고 발사 순서로 전투를 풀어 가는 Three.js 브라우저 게임입니다. 데스크톱과 세로형 스마트폰 화면을 지원합니다.

## 실행과 검사

Node.js 22 이상에서 실행합니다.

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

Vite가 표시하는 로컬 주소에서 플레이할 수 있습니다. 배포 화면에는 해당 소스 리비전의 `BUILD` 표식이 표시됩니다.

## 게임 방법

1. 모드와 권총을 선택합니다. 프리 모드는 기존 자유 보급 실험 환경이며, 초기 탄약 지급 모드는 권총별 특수탄을 가지고 시작합니다. 표준탄은 모두 무제한입니다. 탄약을 눌러 탄창에 넣고 순서를 정합니다.
   탄창이 비어 있으면 장전 버튼이 ‘턴 넘김’으로 바뀝니다. 누르면 사격 없이 감염체 행동을 진행하며, M500도 실린더 선택을 생략합니다.
2. 상처는 적의 체력과 따로 누적됩니다. 상처가 임계치 6에 닿으면 6을 소비하고 발동 턴을 포함해 2턴 동안 취약해져 후속 사격의 체력 피해가 50% 증가합니다. 열상탄은 취약 대상에게 체력 피해가 100% 증가합니다.
3. 폭발은 임계치 없이 적에게 누적되며 턴이 지나도 유지됩니다. 충격 1 이상인 탄약이 명중하면 전량 소비하여 폭발 수치 ×2의 추가 피해를 줍니다. 거리·반동·취약은 이 추가 피해에 영향을 주지 않습니다.
4. 충격은 적의 다음 행동을 중단하는 데 쓰입니다. 충격이 행동 임계치에 닿으면 그만큼 소비하고 나머지는 유지됩니다.
5. 반동은 한 탄창의 발사 순서에서 누적됩니다. 이번 탄까지 누적한 반동이 허용치 3을 넘으면 그 탄부터 화력이 감소합니다. 반동탄은 누적 반동을 피해로 바꾸고 소비합니다.
6. 돌진탄은 사격 전에 2m 접근합니다. 후퇴탄과 후퇴 절개탄은 현재 거리에서 사격한 뒤 2m 물러납니다.
7. 권총 정보 펼침 메뉴에서 다시 시작하거나 모드 선택으로 돌아갈 수 있습니다. 다시 시작은 모드·권총을 유지하고 최초 지급량으로 초기화합니다. 종료 화면에도 두 버튼이 있습니다.

실제 발사한 특수탄만 현재 잔량에서 차감되며 보유량은 유지됩니다. 초기 탄약 지급 모드는 조우가 처치 또는 패배로 끝나면 사용한 탄약을 복구합니다. 수동 보급·영구 제거로 바뀐 보유량은 유지합니다. 프리 모드의 기존 구간별 잔량 복구는 그대로입니다. 재시작하면 탄약 배분·휴대 용량·부착물을 최초 상태로 초기화합니다. 지급표와 복구 경계는 [게임 모드 문서](docs/GAME_MODES.md)에 있습니다.

상처계열 특수탄 4종은 기본 화력 2·상처 3·반동 1입니다. 파열탄은 자신이 취약을 발동하면 추가 피해 4를 주고, 심부 절개탄은 취약을 3턴 유지합니다. 재개방탄은 사격 시작 시 취약한 표적에 상처 6을 줍니다. 흉터탄은 자신이 취약을 발동하면 초과 상처에 더해 최대 2를 남기되, 잔량은 임계치 미만으로 제한합니다. 돌진 절개탄은 제거되었습니다.

탄약·부착물 전체 수치와 설계 결정은 [전투 시스템 문서](docs/COMBAT_OVERHAUL.md)에 있습니다.

최신 46종 탄약과 탄약 연계·탄창 배열 규칙은 [탄약 계층 문서](docs/AMMO_LAYERS.md), 필터 가능한 전체 수치는 [탄약 Excel 명세](docs/ZombieShot_Ammo_Spec.xlsx)에 있습니다. 수치 변경 뒤 `npm run export:ammo`로 명세를 갱신하고 `npm run check:ammo-spec`으로 코드와 대조합니다.

폭발탄 3종의 수치와 비교 결과는 [폭발 밸런스 기록](docs/EXPLOSIVE_AMMO.md)에 있습니다.

저충격탄·강타탄·연쇄충격탄·충격증폭탄의 수치와 발사 순서 비교는 [충격 밸런스 기록](docs/IMPACT_AMMO.md)에 있습니다.

## 배포

일반 개발 작업은 `develop`에서 작업 브랜치를 만들고 PR 검사 뒤 `develop`에 병합합니다. GitHub Pages는 `develop`의 정확한 통합 리비전에서만 배포합니다. `release`와 `main`은 별도의 승격 결정을 거칩니다.

권총 선택·네 고유 특성·주계열과 최신 밸런스 비교: [권총 시스템](docs/PISTOL_WEAPONS.md). 모든 권총은 기존 P220 모델을 공유한다.
