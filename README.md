# 좀비 샷

탄약을 골라 탄창에 배치하고 발사 순서로 전투를 풀어 가는 Three.js 브라우저 게임입니다. 데스크톱과 세로형 스마트폰 화면을 지원합니다.

## 실행과 검사

Node.js 22 이상에서 실행합니다.

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

Vite가 표시하는 로컬 주소에서 플레이할 수 있습니다. 배포 화면에는 해당 소스 리비전의 `BUILD` 표식이 표시됩니다.

## 게임 방법

1. 기본 볼탄은 무제한입니다. 상처탄 3발과 열상탄 3발도 가지고 시작합니다. 탄약을 눌러 최대 4발의 탄창에 넣고 순서를 정합니다.
2. 상처는 적의 체력과 따로 누적됩니다. 상처가 생긴 적은 취약하며, 열상탄은 기존 상처만큼 강해집니다.
3. 충격은 적의 다음 행동을 중단하는 데 쓰입니다. 충격이 행동 임계치에 닿으면 그만큼 소비하고 나머지는 유지됩니다.
4. 반동은 한 탄창의 발사 순서에서 누적됩니다. 허용치 3을 넘은 반동은 후속 탄의 화력을 낮춥니다. 반동 전환탄은 누적 반동을 피해로 바꾸고 소비합니다.
5. 전진탄과 전진 절단탄은 사격 전에 2m 접근합니다. 후퇴탄과 후퇴 절단탄은 현재 거리에서 사격한 뒤 2m 물러납니다.
6. 구간을 완료하면 탄약 배분 1발 또는 휴대 탄약 용량 +2를 선택할 수 있습니다. 특수 감염체 보상으로 얻은 부착물은 장전 화면에서 장착합니다.

실제 발사한 특수탄만 구간 잔량에서 차감됩니다. 다음 구간에 진입하면 런 배분에 따라 잔량이 회복됩니다. 사망 또는 재시작 시 휴대 용량 강화와 부착물 소유가 초기화됩니다.

탄약·부착물 전체 수치와 설계 결정은 [전투 시스템 문서](docs/COMBAT_OVERHAUL.md)에 있습니다.

## 배포

일반 개발 작업은 `develop`에서 작업 브랜치를 만들고 PR 검사 뒤 `develop`에 병합합니다. GitHub Pages는 `develop`의 정확한 통합 리비전에서만 배포합니다. `release`와 `main`은 별도의 승격 결정을 거칩니다.
