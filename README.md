# 좀비 샷

탄창에 넣는 탄약의 **종류와 발사 순서**로 전투 결과가 달라지는 브라우저 전술 장전 게임입니다. 모바일에서도 정밀 드래그 없이 탄창을 편집할 수 있으며, 선택한 순서가 3D 장전과 사격 연출에 그대로 반영됩니다.

## 기술 구성

- Three.js
- TypeScript(엄격 모드)
- Vite
- Vitest
- ESLint

## 로컬 실행

Node.js 22 이상과 npm을 권장합니다.

```bash
npm install
npm run dev
```

Vite가 출력한 로컬 주소를 브라우저에서 열면 게임을 플레이할 수 있습니다.

## 개발 명령

```bash
npm run dev       # 개발 서버
npm run build     # 타입 검사 및 프로덕션 빌드
npm run test      # 결정론적 게임 규칙 테스트
npm run lint      # 정적 코드 검사
```

## 게임 방법

1. 하단 탄약을 눌러 1~4발을 탄창에 넣습니다.
2. 슬롯 순서가 왼쪽부터 실제 발사 순서입니다. 번호와 탄약 이름으로도 순서를 확인할 수 있습니다.
3. 탄창을 편집할 때 다음 방법을 사용할 수 있습니다.
   - 탄약 탭: 빈자리에 추가
   - 장전된 슬롯 탭 → 다른 슬롯 탭: 선택 탄환 이동
   - 장전된 슬롯 탭 → 탄약 탭: 선택 탄환 교체
   - 장전된 슬롯 탭 → `선택 탄 제거`: 선택 탄환 제거
   - 마우스·펜·터치 드래그: 탄약 삽입·교체 또는 장전된 탄환 이동
4. `탄창 장전`을 누르면 개별 탄환 삽입, 탄창 결합, 슬라이드 장전 후 자동 사격합니다.
5. 살아남은 좀비는 화상 피해를 받은 뒤 2m 접근합니다. 거리가 0m가 되면 게임 오버입니다.
6. 좀비를 처치하면 최대 체력이 증가한 다음 좀비가 등장합니다.

탄약 수치와 적 진행 수치는 `src/data/ammoDefinitions.ts`에서 한곳에 관리합니다. 전투 계산은 Three.js 장면과 분리되어 있어 렌더러 없이 테스트할 수 있습니다.

## 탄약

- **표준탄**: 거리와 무관한 안정적인 직접 피해
- **예광탄**: 직접 피해는 낮지만 바로 다음 탄환의 피해를 1.65배로 증폭
- **파편탄**: 5m 이내에서는 강하고 먼 거리에서는 피해 감소
- **소이탄**: 직접 피해와 함께 적 행동 단계에 적용되는 화상 부여

## 빌드와 배포

```bash
npm run build
```

결과물은 `dist/`에 생성됩니다. Vite 기본 경로가 `/Zombie-Shot/`으로 설정되어 GitHub Pages 프로젝트 하위 경로에서 동작합니다.

`.github/workflows/deploy-pages.yml`은 검증된 `release` 브랜치 푸시 시에만 의존성 설치, 테스트, 빌드 후 `dist/`를 GitHub Pages에 배포합니다. `develop`에서는 자동 배포하지 않습니다. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 한 번 설정해야 할 수 있습니다.

## 브랜치 작업 흐름

기능 및 수정 브랜치는 `develop`에서 분기해 작업하고 검증 후 `develop`에 병합합니다. 실제 기기 확인까지 완료한 배포 후보만 `release`에 반영하며, GitHub Pages는 `release`만 배포합니다.

```text
feature/fix → develop → 사용자 검증 → release → GitHub Pages
```

`main`은 초기 안정 기준선으로 유지합니다.

## 실제 휴대전화 확인 목록

- 탄환 선택·이동·교체·제거가 손가락으로 편한지
- 탄창을 드래그하는 동안 페이지나 주소창이 의도치 않게 움직이지 않는지
- 세로·가로 화면에서 버튼, 체력, 거리, 단계 정보가 읽히는지
- 주소창이 접히거나 나타날 때 하단 조작부가 잘리지 않는지
- 연속 장전·사격 중 프레임 속도가 안정적인지
- 첫 사용자 조작 뒤 효과음이 재생되고 무음 상태에서도 진행 가능한지
- 게임 오버와 다시 시작 버튼을 쉽게 누를 수 있는지

## 현재 한계

- 권총, 탄창, 좀비는 가벼운 절차적 저폴리 모델이며 추후 GLTF 에셋으로 교체할 수 있습니다.
- 효과음은 라이선스 의존성이 없는 Web Audio 합성이며 별도 음량·음소거 설정은 아직 없습니다.
- 하나의 좀비 유형과 단순 체력 증가만 구현되어 있습니다.
- 일부 구형 모바일 브라우저의 Pointer Events 동작과 기기별 오디오 정책은 실제 기기 확인이 필요합니다.
- 저장, 영구 성장, 상점, 다중 무기, 웨이브 시스템은 의도적으로 포함하지 않았습니다.
