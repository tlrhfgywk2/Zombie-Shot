# 좀비 샷

탄창에 넣는 탄약의 **종류와 발사 순서**로 전투 결과가 달라지는 브라우저 전술 장전 게임의 첫 번째 플레이 가능 프로토타입입니다.

## 기술 구성

- Three.js
- TypeScript(엄격 모드)
- Vite
- Vitest
- ESLint

## 로컬 실행

Node.js 22 이상과 npm을 권장합니다.

```bash
npm install
npm run dev
```

Vite가 출력한 로컬 주소를 브라우저에서 열면 게임을 플레이할 수 있습니다.

## 개발 명령

```bash
npm run dev       # 개발 서버
npm run build     # 타입 검사 및 프로덕션 빌드
npm run test      # 결정론적 게임 규칙 테스트
npm run lint      # 정적 코드 검사
```

## 게임 방법

1. 하단 탄약을 눌러 1~4발을 탄창에 넣습니다.
2. 슬롯 순서가 왼쪽부터 실제 발사 순서입니다. 슬롯을 누르면 제거되고, 데스크톱에서는 드래그로 교체하거나 순서를 바꿀 수 있습니다.
3. `탄창 장전`을 누르면 장전, 탄창 삽입, 약실 장전 후 자동 사격합니다.
4. 살아남은 좀비는 화상 피해를 받은 뒤 2m 접근합니다. 거리가 0m가 되면 게임 오버입니다.
5. 좀비를 처치하면 최대 체력이 증가한 다음 좀비가 등장합니다.

탄약 수치와 적 진행 수치는 `src/data/ammoDefinitions.ts`에서 한곳에 관리합니다. 전투 계산은 Three.js 장면과 분리되어 있어 렌더러 없이 테스트할 수 있습니다.

## 탄약

- **표준탄**: 거리와 무관한 안정적인 직접 피해
- **예광탄**: 직접 피해는 낮지만 바로 다음 탄환의 피해를 1.65배로 증폭
- **파편탄**: 5m 이내에서는 강하고 먼 거리에서는 피해 감소
- **소이탄**: 직접 피해와 함께 적 행동 단계에 적용되는 화상 부여

## 빌드와 배포

```bash
npm run build
```

결과물은 `dist/`에 생성됩니다. Vite 기본 경로가 `/Zombie-Shot/`으로 설정되어 GitHub Pages 프로젝트 하위 경로에서 동작합니다.

`.github/workflows/deploy-pages.yml`은 `main` 브랜치 푸시 시 의존성 설치, 테스트, 빌드 후 `dist/`를 GitHub Pages에 배포합니다. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 한 번 설정해야 할 수 있습니다.

## 현재 한계

- 권총, 탄창, 좀비, 탄환은 교체 가능한 Three.js 기본 도형 표현입니다.
- 효과음은 외부 에셋 없이 Web Audio API로 합성한 임시 음향이며 별도 음량 설정은 없습니다.
- 하나의 좀비 유형과 단순 체력 증가만 구현되어 있습니다.
- 모바일은 탭으로 추가·제거할 수 있지만 슬롯 간 드래그 재배열은 데스크톱 브라우저에 우선 대응합니다.
- 저장, 영구 성장, 상점, 다중 무기, 웨이브 시스템은 의도적으로 포함하지 않았습니다.
