# 좀비 샷

탄약을 골라 탄창에 배치하고 발사 순서로 전투를 풀어 가는 Three.js 브라우저 게임입니다. 데스크톱과 세로형 스마트폰 화면을 지원합니다.

## 실행과 검사

Node.js 22 이상에서 실행합니다.

```bash
npm ci
npm run dev
npm test
npm run lint
npm run build
```

Vite가 표시하는 로컬 주소에서 플레이할 수 있습니다. 배포 화면에는 해당 소스 리비전의 `BUILD` 표식이 표시됩니다.

## 전투 시험장

시작하면 P220에 표준탄이 모두 장전되어 있다. 바꿀 칸을 고른 뒤 탄약을 누른다. 화살표로 순서를 바꾸고 네 칸을 채워 발사한다. 사격 기록에서 발사별 피해와 체력 변화를 확인할 수 있다. 감염체가 살아남으면 한 번 접근하며 접촉 즉시 패배한다. 다시 시작하면 현재 배치를 그대로 시험할 수 있다. 전투 설정에서 체력, 시작 거리, 턴당 접근 거리를 정하고 새 전투에 적용한다.

구현과 재현 방법은 [전투 시험 기록](docs/validation/combat-core/검증기록.md)에 있다.

탄약별 피해, 같은 탄창의 순서 차이, 무작위 조우의 오류는 명령줄에서 검사할 수 있다. [분석 도구 사용법](docs/combat-analysis-guide.md) · [실측 밸런스 보고서](docs/combat-analysis-report.md)

### 충격 전이와 연속 타격

같은 턴에 같은 적에게 준 직전 타격의 최종 피해가 다음 타격에 영향을 준다. 두 타격의 고유 충격 전이율 중 높은 값 하나를 직전 최종 피해에 곱하고 소수점을 버린다. 이번 타격의 최종 피해는 취약·무기 열 등 보정이 끝난 피해에 현재 상처와 이 전이 보너스를 더한 값이다. 기록에는 이번 타격의 최종 피해와 **자체 전이율**이 남는다. 예를 들어 매개탄 다음에 맥동탄을 쏘면 맥동탄 첫 타격에는 40%, 둘째 타격에는 20%가 적용된다.

| 탄약 | 계열 | 타격 순서와 기본 피해 | 타격별 고유 전이율 |
| --- | --- | --- | --- |
| 매개탄 | 충격 | 4 | 40% |
| 맥동탄 | 충격 | 4 → 4 | 각각 20% |
| 쐐기탄 | 체력 | 2 → 8 | 각각 0% |
| 집속탄 | 체력 | 4 + 이번 턴 이 적에게 이미 준 유효 타격 수 × 2, 한 번 | 0% |

네 탄 모두 한 칸에서 한 발을 쏘고 열이 5 오른다. 분열·추격·맥동·쐐기의 각 타격은 직전 타격이 끝난 상태를 읽는다. 집속탄은 앞선 타격 수를 소비하지 않는다. 복제탄은 기존 규칙대로 원본 발사의 타격 구성과 조건부 보너스를 복제하며, 전이는 복제 타격 시점에 계산한다.

살아 있는 적에게 플레이어가 양의 기본 보정 피해를 실제로 준 경우에만 기록과 횟수를 갱신한다. 상처·전이·조건부 증폭은 한 타격의 구성 요소다. 상태만 부여하거나 반향을 예약하는 시점에는 타격이 생기지 않는다. 반향은 턴 끝에 예약 순서대로 당시 상처와 직전 피해를 읽어 고유 전이율 0%로 타격한다. 이후 상처를 절반으로 줄여 내림하고 타격 기록을 비운 뒤 적이 행동한다. 적을 처치하면 남은 타격과 반향을 버린다.

시험장은 전투를 메모리에만 유지한다. 기존 시험장 탄약에 전이율이 생략되면 0%를 쓴다. 아래 중지된 모드의 정수 충격은 해당 모드의 별도 수치다.

## 이전 버전의 게임 방법 (현재 중지)

1. 프리 또는 탐험 모드와 권총을 선택합니다. 두 모드 모두 권총별 특수탄을 가지고 시작하며, 프리 모드는 자유 보급을 지원합니다. 표준탄은 모두 무제한입니다. 탄약을 눌러 탄창에 넣고 순서를 정합니다.
   탄창이 비어 있으면 장전 버튼이 ‘턴 넘김’으로 바뀝니다. 누르면 사격 없이 감염체 행동을 진행하며, M500도 실린더 선택을 생략합니다.
2. 상처는 적의 체력과 따로 누적됩니다. 상처가 임계치 6에 닿으면 6을 소비하고 발동 턴을 포함해 2턴 동안 취약해져 후속 사격의 체력 피해가 50% 증가합니다. 열상탄은 취약 대상에게 체력 피해가 100% 증가합니다.
3. 폭발은 임계치 없이 적에게 누적되며 턴이 지나도 유지됩니다. 충격 1 이상인 탄약이 명중하면 전량 소비하여 폭발 수치 ×2의 추가 피해를 줍니다. 거리·반동·취약은 이 추가 피해에 영향을 주지 않습니다.
4. 충격은 적의 다음 행동을 중단하는 데 쓰입니다. 충격이 행동 임계치에 닿으면 그만큼 소비하고 나머지는 유지됩니다.
5. 반동은 한 탄창의 발사 순서에서 누적됩니다. 이번 탄까지 누적한 반동이 허용치 3을 넘으면 그 탄부터 화력이 감소합니다. 반동탄은 누적 반동을 피해로 바꾸고 소비합니다.
6. 돌진탄은 사격 전에 2m 접근합니다. 후퇴탄과 후퇴 절개탄은 현재 거리에서 사격한 뒤 2m 물러납니다.
7. 권총 정보 펼침 메뉴에서 다시 시작하거나 모드 선택으로 돌아갈 수 있습니다. 다시 시작은 모드·권총을 유지하고 최초 지급량으로 초기화합니다. 종료 화면에도 두 버튼이 있습니다.

다수전은 동시에 최대 두 감염체가 등장합니다. 카드나 3D 감염체를 눌러 조준하고, 장전한 탄을 한 발씩 발사합니다. 표적 전환은 무료이며 탄약 순서와 반동을 유지합니다. 탄창마다 예고한 한 마리만 행동합니다. 증원과 진행도는 전투 준비부터 표시됩니다. [다수 조우 규칙](docs/다수_조우.md)에 세부 동작을 정리했습니다.

실제 발사한 특수탄만 현재 잔량에서 차감되며 보유량은 유지됩니다. 두 모드 모두 모든 감염체와 증원을 처치하거나 패배로 조우가 끝나면 사용한 탄약을 복구합니다. 개별 적 처치로는 복구되지 않습니다. 수동 보급·영구 제거로 바뀐 보유량은 유지합니다. 재시작하면 탄약 배분·휴대 용량·부착물을 최초 상태로 초기화합니다. 지급표와 복구 경계는 [게임 모드 문서](docs/GAME_MODES.md)에 있습니다.

상처계열 특수탄 4종은 기본 화력 2·상처 3·반동 1입니다. 파열탄은 자신이 취약을 발동하면 추가 피해 4를 주고, 심부 절개탄은 취약을 3턴 유지합니다. 재개방탄은 사격 시작 시 취약한 표적에 상처 6을 줍니다. 흉터탄은 자신이 취약을 발동하면 초과 상처에 더해 최대 2를 남기되, 잔량은 임계치 미만으로 제한합니다. 돌진 절개탄은 제거되었습니다.

탄약·부착물 전체 수치와 설계 결정은 [전투 시스템 문서](docs/COMBAT_OVERHAUL.md)에 있습니다.

최신 46종 탄약과 탄약 연계·탄창 배열 규칙은 [탄약 계층 문서](docs/AMMO_LAYERS.md), 필터 가능한 전체 수치는 [탄약 Excel 명세](docs/ZombieShot_Ammo_Spec.xlsx)에 있습니다. 수치 변경 뒤 `npm run export:ammo`로 명세를 갱신하고 `npm run check:ammo-spec`으로 코드와 대조합니다.

폭발탄 3종의 수치와 비교 결과는 [폭발 밸런스 기록](docs/EXPLOSIVE_AMMO.md)에 있습니다.

저충격탄·강타탄·연쇄충격탄·충격증폭탄의 수치와 발사 순서 비교는 [충격 밸런스 기록](docs/IMPACT_AMMO.md)에 있습니다.

## 배포

일반 개발 작업은 `develop`에서 작업 브랜치를 만들고 로컬 검증·커밋·푸시 후 PR을 엽니다. 에이전트가 변경분을 직접 검토하고, 최신 `develop` 기준 필수 CI가 통과하고 검토 대화가 모두 해결되면 문제가 없는 PR을 직접 병합합니다. 병합과 배포가 확인된 작업 브랜치만 현재 끝 커밋의 통합 근거를 기록하고 정리합니다. GitHub Pages는 `develop`의 정확한 통합 리비전에서만 배포합니다. `release`와 `main`은 별도의 승격 결정을 거칩니다.

권총 선택·네 고유 특성·주계열과 최신 밸런스 비교: [권총 시스템](docs/PISTOL_WEAPONS.md). 모든 권총은 기존 P220 모델을 공유한다.
