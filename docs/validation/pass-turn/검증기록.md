# 빈 탄창 턴 넘김 검증

2026-10-09. 빈 탄창의 공유 장전 버튼을 ‘턴 넘김’으로 표시하고 활성화했다. 누르면 장전·사격·탄창 폐기·M500 실린더 선택 없이 감염체 행동 처리를 한 번 실행한다. 한 발 이상 장전하면 기존 ‘탄창 장전’ 또는 ‘실린더 장전’으로 돌아간다.

- 소스 테스트 31파일·507개 통과. 두 모드·네 권총의 무사격 턴, 탄약·체력 보존, 적 접근과 턴 경과, 중복 입력 방지, 상태 효과의 턴 경과, M500 빈 턴의 근접 패배를 검증했다. 기존 유탄창 전투와 실린더 선택 테스트도 통과했다.
- 타입 검사·Vite 빌드·린트 통과. 로컬 npm 실행 파일이 없어 npm 스크립트의 도구를 Node로 직접 실행했다.
- Edge 실제 렌더링: 데스크톱 1440×900, 세로 390×844에서 빈 탄창·한 발 장전·제거 후 빈 탄창과 버튼 전환을 확인했다. P220과 M500의 실제 빈 턴을 진행했으며, M500 실린더 선택 화면이 나타나지 않는 것을 확인했다. 브라우저 오류 없음.
- 별도 전투 버튼이나 설명 문구를 추가하지 않았다. 빈 턴도 기존 적 행동·상태 효과·패배 판정을 따른다.
