# 특수 감염체 단계 검증 기록

## 수치 비교

실제 `Encounter`, `Player`, `CombatResolver`를 사용한 결정적 시뮬레이션이다. 애니메이션과 보상만 생략하며 모든 탄약 수치는 기존 정의를 사용한다. 아래 발수는 실제 발사 수이며 처치 뒤 미발사 탄은 제외한다. 기본 무기는 P220, 별도 표기가 없으면 부착물이 없다.

| 사례 | 턴 | 실제 발수 | 특수탄 소모 | 발당 체력 피해 |
| --- | ---: | ---: | ---: | ---: |
| 일반 감염체 · 고압탄→고압탄→반동탄→표준탄 | 1 | 4 | 3 | 5.50 |
| 방패 · 같은 조합 즉시 연사 | 2 | 7 | 3 | 4.57 |
| 방패 · 표준탄 한 발 뒤 같은 조합으로 노출 활용 | 2 | 5 | 3 | 6.40 |
| 방패 · 확장 탄창, 접착폭약탄 4발→평두탄 | 1 | 5 | 5 | 6.40 |
| 방패 · 표준탄 뒤 강타탄으로 돌진 중단 | 4 | 8 | 1 | 4.00 |
| 방패 · 표준탄 뒤 후퇴탄으로 거리 확보 | 3 | 6 | 1 | 5.33 |
| 광란 · 고압탄→고압탄→반동탄 | 1 | 3 | 3 | 10.67 |
| 광란 · 강타탄→평두탄으로 돌격 중단 | 3 | 7 | 2 | 4.57 |
| 교란 · 표준탄 뒤 강타탄으로 교란 중단 | 4 | 8 | 1 | 4.00 |
| 교란 · 표준탄 두 번으로 교란을 수용하고 복원 | 4 | 7 | 0 | 4.57 |
| 방패·광란 동시 · 표준탄 | 4 | 13 | 0 | 4.92 |
| 방패·교란 동시 · 표준탄 | 4 | 14 | 0 | 4.57 |

지정 탄창 뒤에는 표준탄으로 이어 간다. 노출 활용과 즉시 연사는 같은 특수탄 3발, 같은 2턴이지만 노출 활용이 실제 발수를 7→5로 줄인다. 동일 거리 7 m의 높은 체력 비교 표적에서 같은 고압·고압·반동·표준 탄창은 방어 단계 15, 준비 노출 단계 35 피해다. 실제 방패 체력은 32이며 이 비교용 높은 체력은 게임 적 수치에 반영하지 않는다.

강한 폭발 빌드는 첫 탄창에 방어 단계 그대로 처치한다. 방어 붕괴나 최소 전투 시간을 요구하지 않는다. 반면 강타탄과 후퇴탄은 특수탄 한 발만 쓰고 생존하는 다른 방법이며, 충격 중단 경로는 거리를 유지하고 후퇴 경로는 돌진을 허용하면서 더 멀리 남는다. 모든 조우를 의도적으로 길게 만들지 않았다.

전체 결과는 [수치 원본](balance.json)에 있다.

## 자동 검증

- 저장소 소스 테스트: 39개 파일, 746개 테스트 통과. 로컬에 남아 있는 과거 사본 폴더는 추가 실행에서 제외했다. 기본 `npm test`도 앞선 실행에서 통과했다.
- 새 행동·시뮬레이션 테스트는 요청한 일반 초탄 처치, 방패 즉시 처치·노출 효율·중단·후퇴, 광란 치명 공격 중단·노출 처치, 교란 예고·중단·적용·복원, 독립 다수 단계와 강한 빌드 유지를 검증한다.
- 상태 테스트는 사격 도중 단계 고정, 세 번 명중·큰 피해·폭발에 의한 방어 붕괴, 모든 탄약의 예측/실사격 일치와 화력 합계, 자기 행동 기회 수, 점화·취약·초과 충격 수명을 포함한다.
- 장비 테스트는 호환·활성 슬롯 선택, 빈 장비·탄창 장착물만 보유한 경우의 대체 효과, 기존 더 긴 교란 보존, 용량 유지, 후퇴로 인한 사거리 보류를 포함한다.
- 네 무기 × 단독·다수 여섯 구성 × 기본·2 m 불이익 = 48개 표준탄 시뮬레이션 전부 생존·승리했다.
- 실제 `Game` 통합 테스트는 네 무기에서 새 다수 조우의 턴별 상태와 분석기 결과를 대조한다.
- 정적 분석, TypeScript를 포함한 프로덕션 빌드, 탄약 Excel 명세 47행·51열 대조 통과. 기존 단일 번들 크기 경고는 남아 있다.

## 렌더링 검증

Edge 기반 실제 WebGL 브라우저에서 데스크톱 1440×900과 세로 390×844, 각각 아래 15개 상태를 확인했다.

1. 방어·빈 탄창
2. 방어·모든 기본 슬롯 장전
3. 방어 붕괴 뒤 회복
4. 돌진 준비 노출과 강한 탄창
5. 강타탄으로 돌진 중단 뒤 회복
6. 후퇴탄 뒤 실제 돌진과 2.5 m 거리
7. 광란 준비와 예상 처치 후 미발사 슬롯
8. 교란 준비와 실제 장착물 대상
9. 실행 직전 교란 예고
10. 장착물 1턴 비활성화
11. 다음 기회에 장착물 복원
12. 다수·빈 탄창
13. 다수·긴 이름·6칸 장전·여러 상태 수치
14. 한 적만 단계 전환한 독립 상태
15. 근접 치명 공격 두 개의 예고와 교대 순서

탄 그림, 제목, 수치와 컨테이너 경계를 스크린샷으로 직접 확인했다. 페이지·단계·표적·탄창 슬롯의 화면 밖 넘침과 브라우저 오류가 없었다. 기본 플레이에서 진단 표시는 나타나지 않으며 `BUILD LOCAL` 표시는 유지됐다. 세로 화면의 전투 준비 표시가 단계 정보를 가리던 문제는 적 카드 높이를 관찰해 위치를 계산하도록 수정했다.

## 재현 명령

```sh
npm test
npm test -- --exclude '**/*.local/**'
npm run lint
npm run build
npm run check:ammo-spec
node tools/analyze-special-infected.mjs
npm run dev -- --host 127.0.0.1 --port 5178 --strictPort
node tools/validate-special-infected.mjs
```

브라우저 검증은 Playwright가 필요하며 프로젝트 의존성을 늘리지 않았다. 외부 설치 경로는 `PLAYWRIGHT_MODULE`, 다른 미리보기 주소는 `VALIDATION_BASE`로 전달한다.

## 남은 한계

피할 수 없는 사망은 위 시나리오에서 발견하지 못했지만 모든 합법적 탄약 배열·거리·부착물 조합의 생존을 보장하는 완전 탐색은 아니다. 준비 중에도 공격·교란을 무시하고 낮은 피해만 반복하면 예고된 치명 공격으로 패배할 수 있다. 빈 탄창을 반복하면 적이 접근해 결국 치명 공격을 하므로 유리한 단계에 머무는 무한 대기는 불가능하다.

전용 모델·애니메이션은 추가하지 않았다. 새 세 유형은 프리 모드 4~6조우에 노출하며 탐험 생성 풀은 유지했다. 이후 실제 플레이 자료로 배율·이동·단계 길이를 조정하고 탐험 편입을 별도로 검토할 수 있다.
