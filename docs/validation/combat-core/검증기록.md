# P220 전투 시험장

기준은 `develop`의 `666fbdbf7fab352b793b271dbd5754945f3ffa87`, 작업 브랜치는 `prototype/combat-core-reset`이다. 가져온 로컬·원격 참조, 공개 PR 이력, 관련 커밋과 실제 시작 경로에서 이전 클라우드 초기화 구현을 찾지 못해 새로 구현했다.

## 실행과 판정

Node.js 22 이상에서 `npm ci`, `npm run dev -- --host 127.0.0.1`을 실행하고 표시된 주소의 `/Zombie-Shot/`을 연다. 표준탄 네 발로 시작한다. 칸 선택 뒤 탄약을 누르면 다음 칸으로 넘어간다. 화살표는 인접한 두 칸을 교환한다. 설정의 양의 정숫값은 적용 버튼을 눌러 새 전투를 시작할 때 반영된다. 기본 체력 100, 거리 3, 접근량 1은 시험용 값이다.

- `src/prototype/rules.ts`에서 일곱 탄의 수치, 탄창 용량, 시나리오, 순차 판정을 관리한다. 강화탄 20은 실험값이다. 거리와 무기 특성은 피해식에 들어가지 않는다.
- 취약은 발동 즉시 25%·2턴이 되며 다음 정리 단계에서 1턴이 된다. 고통탄은 자기 피해 계산에서만 보너스를 두 배로 사용한다. 후속탄은 직전 탄의 반올림된 계산 피해를 읽는다. 처형탄은 발사 직전 체력으로 판정한다.
- `src/prototype/CombatController.ts`는 완전한 탄창을 잠그고 발사 순서를 실행한다. 초기화는 대기 타이머를 제거하고 이전 실행 세대를 무효화한다. 살아남은 적이 한 번 접근하며 접촉하면 즉시 패배한다. 승리·패배 모두 플레이어 행동을 한 번만 센다.
- `src/main.ts`는 `CombatView.ts`로 직접 진입한다. 이전 게임 제어기, 인벤토리, 보상, 탐험, 다른 상태·무기·부착물, 저장된 전투 설정의 이벤트 경로는 시작하지 않는다. 기존 Three.js 모델과 연출 진단은 재사용한다. 사격 기록은 최근 탄창 단위이며 종결 시 계산 피해와 실제 체력 감소를 구분한다.

브라우저 재검증에는 빌드와 Playwright, Edge가 필요하다. 설치되어 있는 Playwright의 `index.mjs` 절대 경로를 `PLAYWRIGHT_MODULE`로 지정할 수 있다. 실행기는 임시 로컬 서버와 브라우저를 종료한다. 실물 휴대전화와 다른 브라우저 엔진은 검사하지 않았다.

양쪽 화면에서 슬롯 비우기, 가득 채우기, 교환, 중복 발사, 초기화, 승패를 확인했다. 취약·강화·후속·종결 순서의 피해는 0·25·26·20이었다. 체력 15인 적은 두 발로 쓰러져 뒤 두 칸이 미발사로 남았고 두 번째 탄의 계산 피해 8에서 실제로는 5만 감소했다. 체력 41에서 표준탄 네 발을 맞힌 뒤 1이 남은 적은 한 걸음 접근해 즉시 패배를 일으켰다. 진단 모드에서 실제 감염체의 깊이 좌표가 중간 발사까지 유지되고 이후 접근한 것도 확인했다. 시험 전에 넣어 둔 이전 설정과 저장값은 그대로 남았다.

## 검토와 운영

자체 검토와 실제 조작에서 상태 표시 선택자가 화면 전체를 덮어쓰던 오류를 찾아 수정하고 같은 시나리오를 재실행했다. 일반 화면에는 진단 요소가 없고 `?presentationDebug=1`에서만 표시된다. 이전 명세 검증기는 서버를 닫을 때 불필요한 의존성 탐색 경고가 발생하여 명세와 관계없는 자동 탐색만 끈 뒤 대조 결과를 재확인했다.

PR 검사는 기존 `validate` 작업에서 새 계약 테스트, 전체 테스트, 이전 명세 대조, 정적 검사, 타입 검사와 빌드를 실행한다. 대상은 `develop`, `release`, `main`이다. 배포 작업은 PR 검사와 분리되어 있다. 실제 원격 검사 리비전과 적용된 보호 설정은 PR 본문에 기록한다.

정리 전 로컬·원격 끝 커밋과 통합 근거를 기록하고 삭제 직전에 다시 확인했다. 원격 삭제는 각 참조의 예상 SHA 조건을 건 단일 원자적 요청으로 수행했다. 로컬 55개, 원격 68개의 삭제를 확인했다. 열린 PR #77·#78, 운영 브랜치, 작업 트리, 통합이 입증되지 않은 사격 자세 수정 브랜치는 보존했다. [브랜치별 근거와 처리 결과](브랜치-정리.md)
