# 모드 선택·초기 탄약 검증

검증일: 2026-10-09. 데스크톱 1440×900, 세로 390×844의 Edge 렌더링을 직접 확인했다. 로컬 화면의 식별자는 `BUILD LOCAL`이다.

## 자동 검사

- 소스 테스트: 31개 파일, 496개 테스트 통과. 로컬에 남은 이전 작업의 `*.local` 복제본은 집계에서 제외했다.
- 전체 기본 테스트 실행도 통과했다. 런 초기화, 네 권총의 정확한 배분, 미지급 탄약 0발, 무제한 표준탄, 예약·소진·복구, 영구 획득·제거 보존, 모드 전환, 동일 설정 재시작을 포함한다.
- 실제 `Game`·`Player`·전투 계산·상태 전환을 사용하고 렌더링·애니메이션만 대체한 제어 테스트로 처치 후 다음 적, 다음 구간, 승리, 패배, 실린더 선택을 확인했다.
- 타입 검사·Vite 프로덕션 빌드·ESLint 통과. 기존 대형 번들 안내는 남아 있다.
- 탄약 Excel 명세 대조: 47행·51열 통과. 탄약 정의나 밸런스를 변경하지 않았다.
- 이 환경에 `npm` 실행 파일이 없어 각 npm 스크립트가 실행하는 저장소 내 도구를 Node로 직접 실행했다. GitHub PR 검사는 원래 npm 스크립트 전체를 실행한다.

## 실제 화면과 조작

| 상태 | 확인 |
| --- | --- |
| 실행 메뉴 | 두 모드 구분, 키보드 초점 순환, 세로 화면 버튼 크기 |
| 권총 선택 | 네 지급표 정확성, 무제한 표준탄, 긴 경량장전탄 이름, 카드·탄 그림·수량의 정렬 |
| 전투 준비 | 빈 탄창과 전체 장전, P220 초탄·평두탄 조합, M500 경량장전탄·연계탄 조합 |
| 실제 발사 | 소진 특수탄 0 / 보유량 표시와 선택 불가, 무제한 표준탄, M500 순서 유지 후 발사 |
| 조기 처치 | 뒤쪽 세 발의 미발사 표시·수치·그림 정렬, 해당 탄 미소모 |
| 복구 | 추가 보급한 초탄 2발, 영구 제거 후 평두탄 1발, 획득한 잔향탄 1발이 승리 후 유지 |
| 재시작 | P220 최초 지급량 초탄 1발·평두탄 2발, 빈 탄창, 훈련 표적 체력·거리와 서 있는 자세 복구 |
| 모드 변경 | 초기 모드에서 프리 모드 M1911로 변경하면 특수탄 0발, 기존 수동 보급으로 절개탄을 추가 가능 |

브라우저 런타임 오류는 없었다. 처치·미발사 경계는 배포에서 제외되는 로컬 검증 HTML에서 실제 게임의 표적 체력을 1로 설정해 확인했다. 자동 테스트의 여러 적·구간 구성도 검증 전용이며 배포 훈련장 구조를 확장하지 않는다.

재시작의 기존 사망 자세 잔류를 발견해 새 런 초기화에서 감염체 자세를 재설정했고, 수정된 렌더링을 다시 확인했다. 총기 애니메이션은 변경하지 않았다.
