# 감염체 행동 표시 검증

2026-10-09, 로컬 개발 빌드(`BUILD LOCAL`)에서 검증했다.

기존 `GameUI`·`GamePresentation`에 실제 `CombatResolver` 결과를 전달하는 저장소 제외 로컬 검증 페이지를 사용했다. 일반 게임 코드는 별도 진단 표시나 검증 진입점을 추가하지 않았다.

데스크톱 1440×900과 세로 390×844에서 다음을 직접 렌더링하고 화면을 확인했다.

- 오염 투척을 예고한 뒤 8 m에서 10 m로 후퇴: ‘오염 투척 지연 → 접근 2.8 m’, 원래 중단 임계치 7 유지.
- 오염 투척 충격 중단: ‘행동 결과 / 오염 투척 · 충격 중단’, 소비 후 충격 0과 원래 임계치 7 표시.
- 근접 충격 뒤 거리 0 m: ‘회복 접근 0.0 m’, 접근의 중단 임계치 4 표시.
- 지반 충격 보류 중 거리 10 m: ‘지반 충격 지연 → 접근 2.8 m’, 유효한 접근만 예고.
- 거리 12 m 초음파 공명: 원거리 능력 예고 유지, 펼친 툴팁에 ‘사거리 0 m 초과 ~ 12 m’ 표시.
- 오염 투척 지연 툴팁: 능력 사거리 8 m와 보류·근접 우선 규칙 표시.

행동 이름·거리·충격 임계치가 컨테이너 안에 있고, 문구 생략이나 겹침 없이 읽히는 것을 확인했다. 툴팁은 세로 화면에서도 경계를 넘지 않았다. 탄창 카드·슬롯 레이아웃 변경은 없다.

이미지는 이 디렉터리의 `desktop-*.png`, `portrait-*.png`에 저장했다. 실제 게임에서도 P220 선택 → 표준탄 한 발 → 장전·사격 → 초음파 공명 실행 → 거리 교란 2턴 → 다음 접근 예고 → 전투 준비 복귀를 확인했고 브라우저 오류가 없었다. 전체 전투 경계 사례의 판정은 자동 테스트로 검증하며, 로컬 검증 페이지의 고정 상태 캡처를 실제 플레이 연속 캡처로 주장하지 않는다.
