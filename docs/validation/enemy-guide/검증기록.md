# 감염체 도감 검증

프리 전투, 탐험 화면, 모드 선택, 권총 선택에서 읽기 전용 도감을 연다. 감염체 10종의 체력·스테이지당 증가·시작 거리·접근 거리·충격 중단 및 상처/점화 임계치·행동 주기를 실제 정의에서 가져온다. 현재 적 생성에는 스테이지 체력 보정이 없어 상승치는 모두 +0이다. 기존 전투 수치는 변경하지 않았다.

Edge 실제 렌더링 1440×900, 390×844에서 네 화면씩 총 8개 상태를 확인했다. 표 시작과 마지막 행동 패턴까지 가로·세로 스크롤, 고정 이름 열·표 머리글, 긴 특수 행동 설명, 10개 전체 행, 닫기·Escape·열기 버튼으로 포커스 복귀를 확인했다. 도감을 여닫아도 현재 체력과 장전한 표준탄 한 발이 유지됐고 런타임 오류는 없었다. 화면은 같은 폴더의 PNG와 results.json에 보존한다.

- 소스 테스트 39파일·746개 통과.
- npm run lint, npm run build 통과. 기존 번들 크기 경고 유지.
- 재현: 로컬 5180 포트에서 미리보기 후 `node tools/validate-enemy-guide.mjs`. 외부 Playwright는 PLAYWRIGHT_MODULE, 다른 주소는 VALIDATION_BASE로 지정한다.
