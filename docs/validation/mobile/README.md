# 모바일 전투 화면 공간 개선 검증

모바일의 부착물 구성, 총기 상세, 음향 설정을 버튼으로 여는 패널로 옮겼다. 탄약은 가로로 넘기는 한 줄로 유지하고, 발사 순서·장전 버튼·상단 상태 정보를 압축했다. 전투 계산과 탄약 소모 규칙은 변경하지 않았다.

## 검증 환경

- 로컬 Vite 실행 화면을 Microsoft Edge의 실제 렌더링으로 확인했다.
- 데스크톱 1440×900, 세로 390×844, 작은 세로 360×640, 회전 후 가로 844×390을 확인했다.
- 자동 검증은 진입점에 게임 참조만 보관한다. 배포 코드에 테스트 참조를 추가하지 않는다.
- 휴대전화 실물 브라우저 검증은 수행하지 않았다.

## 확인 결과

| 화면 | 빈 탄창 하단 UI | 6발 탄창 하단 UI | 전투 영역 높이 |
| --- | ---: | ---: | ---: |
| 390×844 | 266px | 284px | 578px / 560px |
| 360×640 | 266px | 284px | 374px / 356px |

전투 영역 높이는 캔버스 영역이다. 상단 HUD와 결과 예상 카드도 이 영역에 표시된다.

- 빈 상태, 6발 장전, 긴 탄약 이름, 화상·상처·폭발·충격·반동 수치 조합, 처치 예상으로 뒤쪽 5발이 미발사되는 상태를 직접 렌더링했다. 탄 그림·제목·수치가 슬롯 경계를 넘지 않는 것을 캡처에서 확인했다.
- 결과 예상 수치 6개는 세로에서 3열 2행, 가로에서 한 줄로 정렬된다.
- 부착물 패널의 긴 이름, 장착 상태, 소유하지 않은 선택지, 프리 모드의 추가 버튼, 탐험 모드의 추가 버튼 숨김을 확인했다.
- 부착물 추가 → 목록 닫기 → 장착 → 패널 닫기, 음소거, 닫기 버튼, 배경 탭, Escape, 포커스 복귀가 동작한다.
- 손가락 입력으로 탄약 줄을 가로 스크롤하고 길게 눌러 상세 정보를 표시했다. 상세 정보가 화면 안에 표시되며 드래그 표시가 남지 않는다.
- 패널을 연 상태에서 회전·데스크톱 전환해도 배경 입력 잠금이 복구된다. 장착 구성과 음소거 상태가 유지된다. 전투 잠금과 모드 선택으로 이동할 때 패널이 닫힌다.
- 데스크톱은 기존 부착물 구성을 유지한다. 탄약을 모두 보유해도 목록 안에서 스크롤하여 전투 화면 높이를 확보한다.
- 소스 테스트 33개 파일, 558개 테스트 통과. TypeScript 검사, ESLint, 프로덕션 빌드 통과.

## 재현

Vite를 실행하고 Playwright 모듈 경로, 브라우저 채널, 로컬 주소를 환경변수로 지정한다.

```powershell
$env:PLAYWRIGHT_MODULE = '설치된 Playwright의 index.mjs 절대 경로'
$env:BROWSER_CHANNEL = 'msedge'
$env:VALIDATION_BASE = 'http://127.0.0.1:5175/Zombie-Shot/'
node tools/validate-mobile-layout.mjs
```

캡처와 영역 측정값은 이 폴더에 저장된다. 스크립트 검사는 시각 검토를 보완한다.
