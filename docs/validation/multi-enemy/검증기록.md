# 다수 조우 검증

- 날짜: 2026-11-02
- 자동 검증: 현재 소스 36개 테스트 파일, 644개 테스트 통과. 타입 검사·정적 분석·프로덕션 빌드·탄약 Excel 47행 51열 대조 통과.
- 로컬 도구 환경에는 npm 실행 파일이 없어 동일한 프로젝트의 Vitest·ESLint·TypeScript·Vite 진입점을 Node로 실행했다. 과거 실험 복사본인 `*.local` 폴더는 현재 소스 테스트 집계에서 제외했다.
- 렌더링: 로컬 Vite, Edge의 실제 WebGL 렌더링, 1440×900 및 터치 390×844. `BUILD LOCAL` 확인. 일반 실행에서 진단 오버레이 없음.
- 재현: `PLAYWRIGHT_MODULE`에 사용 가능한 Playwright 모듈 경로를 지정하고 `node tools/validate-multi-enemy.mjs` 실행. 기본 브라우저는 Edge이다.

## 확인한 경계 상태

각 해상도에서 단독 빈 탄창, 일반 적 둘의 빈 탄창·전체 장전, 발사 대기, 연속 탄 사이의 표적 전환, 첫 처치와 잔탄, 마지막 표적 예상 처치와 미발사 탄, 위험 조우의 긴 이름·상태 조합·6칸 장전, 처치 예측, 증원 합류, 두 근접 표적을 확인했다. 총 22개 화면과 카드 경계를 `results.json` 및 PNG에 기록했다.

카드의 체력·거리·누적 수치·제목·탄 그림·핵심 수치와 컨테이너 경계를 직접 확인했다. 긴 이름의 카드 넘침, 카드 간 세로 기준선 차이, 데스크톱 카드의 적 머리 가림을 수정했다. 마우스와 실제 터치 입력으로 카드 및 3D 모델 선택을 확인했다. 첫 처치 후 고압탄 소진 0과 남은 표준탄 순서가 유지되고 마지막 표적 처치 뒤의 한 칸이 미발사 표시됨을 검증했다.

## 전투 회귀 범위

독립 상태와 개별 효과, 플레이어 이동의 전체 거리 적용과 경계값, 한 기회당 한 적 행동, 서로 다른 속도·의도, 예정 행동자 처치와 근접 생존자·증원 대체 공격 방지, 중단 후 교대, 기다리는 적의 점화 봉쇄와 재사용 대기, 표적 변경 시 탄약·차례 불변, 전원 처치 복구, 조준 중 초기화·메뉴 복귀, 중복 사격 입력 방지, 47종 탄약의 한 발씩 계산과 기존 연속 계산 일치를 검증했다.

네 권총으로 표준탄만 사용한 일반 둘·질주와 거체·오염과 공명 및 증원 구성, 여러 시드의 전체 탐험 런도 통과했다. 프로덕션 빌드는 Three.js를 포함한 기존 단일 번들 크기 경고가 남는다.
