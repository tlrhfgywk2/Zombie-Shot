# 화상·점화 검증 기록

검증일: 2026-10-03. 브랜치: `codex/burn-ignition-system`. 기본 권총 P220을 사용하고, 무기별 결과는 별도 자동 검사로 확인했다.

## 자동 검사

- Vitest: 23개 파일, 251개 테스트 통과.
- 신규 핵심 검사: `BurnIgnition.test.ts` 54개, `BurnBalance.test.ts` 2개, 기존 `AmmoView.test.ts`에 신규 2개 추가.
- 화상 유지·비감소·자동 피해 없음·즉시 피해·재현성·사망 초기화·임계치·초과분·한 발 한 번·재점화 갱신·세 특수 행동 전체 봉쇄·보통 이동·치명 공격 보존·충격 중단 시 점화 보존을 검사했다.
- 여섯 탄약의 순서별 효과, 취약과 즉시 피해 분리, 폭발의 독립성, 네 권총·세 거리·부착물의 실제/예측 일치, 추가 후보 수치, 등급·중복 없는 추첨·기존 휴대 용량·교체·스테이지 재보급을 검사했다.
- TypeScript: `tsc -b` 통과.
- ESLint: 전체 저장소 통과.
- Vite: 프로덕션 빌드 통과. 기존 600kB 번들 경고는 유지된다.
- 로컬 환경에 `npm` 명령이 없어 패키지의 Node 진입점으로 동일 스크립트를 실행했다. PR 검사에서는 저장소 워크플로가 `npm test`, `npm run lint`, `npm run build`를 실행한다.
- 방어구와 확률 명중은 현재 코드에서 제거되어 해당 적/명중 보정 검증은 적용 대상이 아니다. 기존 거리·반동·교란 경로를 확인했고, 관통 효과를 새로 넣지 않았다.

## 실제 브라우저 전투

설치된 Chrome에서 WebGL을 렌더링하고 보급 선택·장전 버튼·실제 애니메이션·적 행동까지 실행했다. 테스트 상태를 브라우저 내부에 준비하는 임시 외부 검증 스크립트를 사용했으며, 배포 코드에 검증용 전역 변수나 탄약 지급 기능을 추가하지 않았다. 로컬 화면은 `BUILD LOCAL`이다.

| 검증 | 실제 결과 |
|---|---|
| 보급에서 소이탄 선택 | 기존 보급 콜백으로 영구 배분 +1 |
| 원거리에서 소이탄 한 발 | 즉시 합계 피해 4, 화상 8 |
| 같은 적에게 다음 턴 소이탄 | 화상 16 유지, 자동 추가 피해 없음 |
| 오염 투척체 화상 17에 소이탄 | 점화 표시, 초과분 5, 2.8m 접근, 슬롯 봉쇄 없음 |
| 지반 파쇄체 화상 17에 소이탄 | 점화 표시, 초과분 1, 2.8m 접근, 반동 교란 없음 |
| 공명 비명체 화상 17에 소이탄 | 점화 표시, 초과분 7, 3.0m 접근, 거리 교란 없음 |
| 촉진 → 고열 → 발화, 오염 투척체 | 피해 12, 화상 합계 22, 잔량 2, 점화로 특수 행동 봉쇄 |
| 고열 → 촉진 → 발화, 오염 투척체 | 피해 9, 화상 17, 점화 없음, 실제 장착된 레이저 조준기 슬롯 2턴 봉쇄 |
| 저열 → 고열 → 점화, 중거리 | 피해 9, 화상 합계 26, 잔량 6, 점화 |
| 고열 → 고열 → 표준, 중거리 | 피해 12, 후속 탄 반동 감소 |
| 표준 → 고열 → 고열, 중거리 | 피해 13, 앞쪽 표준탄을 반동 감소 전에 사용 |
| 차가운 적에게 점화탄 | 화상 2 |
| 화상 17인 적에게 점화탄 | 화상 10, 점화 후 잔량 7 |
| 보통/점화된 적에게 발화탄, 중거리 | 각각 피해 4/6, 화상 축적은 둘 다 2 |
| 취약·폭발·충격·화상 혼합 | 피해 19, 폭발은 충격 시점에 기폭, 화상은 별도 점화 |

각 사격의 체력과 화상 잔량이 미리보기와 일치했다. 정상적으로 수행한 적 행동 뒤 점화가 해제됐다. 세 특수 적 모두 의도 안내가 봉쇄할 행동 이름과 실제 접근 거리로 바뀌었다. 실행 중 페이지 오류는 없었다.

## 렌더링 확인

1440×900과 390×844에서 빈 탄창, 4칸 전체, 6칸 전체, 긴 이름, 화상·반동 조합, 촉진 배율, 발화 보너스, 예상 처치 뒤 미발사 슬롯, 툴팁, 보급·보유·상세 카드를 확인했다. 탄 그림·제목·숫자·컨테이너 경계를 직접 이미지로 확인했다. 수정 후 슬롯과 전투 수치 컨테이너의 가로·세로 오버플로는 없었다.

발견 후 수정한 사항:

- 점화 표시가 사격 후 조준 복귀까지 늦게 갱신되던 순서를 수정해 후속탄 전에 적 상태를 표시한다.
- 좁은 6칸 탄창에서 촉진 배율과 발화 보너스가 잘렸다. 확장 탄창 장전 버튼을 별도 줄로 옮기고 세로 슬롯 높이를 늘렸다.
- 세로 결과 예측의 두 줄 구성이 준비 화면과 겹쳐 한 줄 여섯 수치로 정리했다. 숫자 안에서 줄이 갈라지지 않도록 여백과 아이콘 크기를 조정했다.
- 촉진·발화 효과는 잔량과 별도 줄로 배치해 읽기 쉽게 했다.

## 남은 밸런스 관찰

즉시 피해와 일부 일반탄 혼합으로도 화상에 기여할 수 있지만, 보급 선택을 포함한 전체 런의 최적 전략을 확정한 검증은 아니다. 소이·표준·고열의 효율, 높은 임계치 적의 제어 빈도, 저열탄의 높은 반동 탄창에서의 채택률을 후속 플레이 기록으로 관찰하면 된다.
