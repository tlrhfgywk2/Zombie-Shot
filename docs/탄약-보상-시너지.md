# 소유 탄약을 반영하는 약한 보상 보정

전투 규칙·피해·임계치·총기·적·부착물을 변경하지 않고 탐험 전투 보상에 약한 연결 보정을 적용한다. 완성 보장은 없으며, 화면 문구와 선택 인터페이스도 유지한다.

## 현행 시스템 감사

- 실제 탐험은 9노드이며 전투는 1·3·6·8깊이, 5깊이의 한 갈래에 있다. 무작위 경로라면 평균 약 4.5회 보상 기회다. 마지막 출구 뒤에는 보상이 없다.
- 탐험 보상은 제한된 11종의 **서로 다른 2개 중 1발 선택**이다. 전체 탄약용 `generateAmmoRewards`의 3개 선택과 혼동하면 안 된다.
- 탐험 후보는 중공탄·고압탄·저반동탄·절개탄·열상탄·강타탄·후퇴탄·돌진탄·연계탄·초탄·종결탄이다. 전부 일반 등급이다. 다른 탄종을 탐험에 새로 해금하지 않는다.
- 상인은 기존에 시드로 정해진 탄약 3발을 특수탄 1발과 교환한다. 보정으로 상점 재고·가격을 바꾸지 않는다. 보급함의 평두탄 2발, 제단의 특수탄 1발→중공탄 2발도 고정이다.
- 소유 탄약은 기본 14발 한도이며 사격 소모는 조우 종료에 복구된다. 거래 지불은 소유권을 영구 차감한다. 보정은 `getBuild()`를 사용하고 발사 직후의 일시 잔량을 사용하지 않는다. 지급은 기존 원자적 `exchangeAmmo`를 통과한다.
- 프리 모드는 자유 보급이며 이 작업으로 새로운 자동 보상 기회를 만들지 않는다.
- `ammo_redesign.md`와 `simulation/model.mjs`의 v7는 별도 제안이다. 18전투, 3지선다, 최초 연결 초안, 제작 등급, 소작탄, 열 소비, 강화된 열상탄은 현행 탐험에 반영된 규칙이 아니다.

## 보정 규칙

`src/progression/AmmoRewards.ts`의 `AMMO_SYNERGY_GUIDANCE`로 조절한다. 선택값은 `chance: 0.5`, `strength: 3`이다.

1. 소유량·탄창 크기에서 실제 연결이 개선되는 후보가 있을 때 이벤트의 50%에서 보정을 시도한다.
2. 그 이벤트에서도 무작위로 정한 선택지 **하나만** 가중 추첨한다. 나머지는 원래 추첨이다.
3. 상대 가중치는 `1 + strength × score`다. 모든 후보의 기본 가중치 1은 유지된다.
4. 전체 탄약용 도우미는 기존 75:25 등급 추첨을 먼저 유지하고, 해당 등급 안에서만 탄종을 가중 추첨한다. 탐험은 원래처럼 11종 균등 기반이며 고급 탄약을 추가하지 않는다.
5. 완성된 같은 방향을 더 쌓아도 점수를 올리지 않는다. 소유한 같은 탄을 반복 받는 점수는 `1 + 소유량 × 0.5`로 나눈다. 새 연결과 미완성 연결의 개선을 보고, 여러 방향의 점수를 합산해 부유한 빌드에 보너스를 몰아주지 않는다.
6. 전투 보상을 처음 표시할 때 별도의 `런 시드:reward:조우 ID` 난수열과 그때의 소유량으로 고정한다. 다시 그리기나 거래로 재추첨할 수 없다. 지도·상점 생성의 기존 난수열은 유지한다. 회피한 전투는 보상을 생성하지 않는다.

탄약의 태그가 같다는 이유만으로 가중치를 주지 않는다. `AmmoSynergy.ts`는 실제 효과 필드와 연계 규칙을 읽어 다음 연결을 판정한다.

| 연결 | 판정의 근거 |
|---|---|
| 상처→취약 | 소유한 상처탄을 탄창에 넣어 상처 6을 채우고 후속 표준탄 한 칸을 남길 수 있는가 |
| 취약→전용 보상 | 취약 발동에 필요한 다른 탄을 확보한 뒤 취약 추가 효과 탄을 쏠 수 있는가 |
| 열 누적→점화 | 탄창 안에서 기본 점화 임계치 20을 준비하는가 |
| 열→증폭 | 열 생성 탄과 현재 열 비례 증폭 탄을 서로 다른 발로 쏠 수 있는가 |
| 폭발→충격 기폭 | 폭발 생성 탄과 실제 충격을 가진 후속 탄이 있는가 |
| 높은 반동→전환·회복 | 반동 3 이상 탄과 반동 전환 또는 회복 탄이 있는가 |
| 충격→증폭 | 증폭식의 제수 이상 충격을 먼저 만들 수 있는가 |
| 후속 강화·복사 | `next`·`copyPrevious`·`replayPrevious` 규칙과 유효한 수치의 다른 탄이 있는가 |

수량을 탄창 크기까지 펼쳐 사용하며, 소비자 한 발을 따로 예약한다. 절개탄 1발은 준비도 0.5이고, 2발과 후속 표준탄은 취약 연결이다. 절개탄 1발에 열상탄만 추가해도 취약이 발동하지 않으므로 완성으로 계산하지 않는다. 배열 조건만 있는 탄과 독립적으로 강한 탄은 자동 연결 대상으로 취급하지 않는다.

이는 보수적인 한 탄창 준비 모델이다. 총기 특성·부착물·복사의 복합 효과로 가능한 모든 연결을 탐색하지 않으며, 적의 조기 처치·개별 열 저항·거리까지 포함한 실전 효과를 보장하지 않는다. 대표 연결은 실제 `CombatResolver`로 교차 검사한다. 현행 11종에는 열·폭발·반동 전환 탄이 없으므로 이들에 대한 전체 탄약 검사는 탐험 결과와 분리한다.

## 원래 확률과 변경 확률

| 조건 | 원래 | 약한 보정 |
|---|---:|---:|
| 탐험에서 특정 탄이 2개 선택지 중 등장, 소유 연결 없음 | 2/11 = 18.18% | 18.18% |
| 소유가 절개탄 1발뿐일 때 추가 절개탄 등장 | 18.18% | **21.75%** |
| 위 조건에서 무관한 각 탄종 등장 | 18.18% | 약 17.83% |
| 전체 탄약 도우미의 등급 추첨 | 일반 75%·고급 25% | 동일 |
| 탐험 선택 수·실제 수령량 | 2개 중 1발 | 동일 |

절개탄 1발의 추가 절개탄 점수는 `0.5 / 1.5 = 1/3`이다. 보정 슬롯에서 상대 가중치는 2, 다른 후보는 1이다. 중복 없는 두 선택지와 보정 슬롯의 위치를 모두 적분한 등장 확률이 21.7459%다. 이 확률은 소유 상태에 따라 달라지며, 특정 탄의 출현을 보장하지 않는다.

## 재현 가능한 비교

```sh
node tools/reward-simulation.mjs exploratory 2000
node tools/reward-simulation.mjs holdout 5000
```

탐색 시드 1,700,001~1,702,000과 독립 확인 시드 2,700,001~2,705,000을 사용한다. 기존 v7 검증에 노출된 시드는 재사용하지 않는다. 40%·50%·60% 보정, 무보정, 강한 보정을 탐색하고, 확인 구간에서는 원래·선택한 50%·강한 보정만 평가했다. 강한 비교는 확률 100%·강도 12로, 이 경우에도 한 선택지만 보정한다. 확인 결과를 보고 운영 가중치를 재조정하지 않았다.

탐험은 실제 `ExplorationRun` 지도, 무기별 초기 탄약, `Player` 거래·한도를 재사용한다. A는 기존 지도 생성 보상, B·C는 별도 보상 난수열을 사용한다. 동일 시드의 지도·경로·초기 소유량은 대응하며, 난수 소비 횟수가 다른 보상 구현의 모든 추첨값 자체가 일치하는 비교는 아니다.

각 모드는 무작위 선택/현재 재고를 보고 연결을 우선하는 선택, 거래·이벤트 생략/실제 비용으로 탄약 거래·고정 보상 수령의 4개 정책을 별도로 기록한다. 무기 4종은 균등 배분된다. 이 실험은 **모든 선택 전투를 생존한 경우의 획득 가능성**이다. 사망률·최적 전투 피해·승률을 이 획득 비율로 주장하지 않는다. 회피하면 보상 기회가 줄어 결과가 낮아질 수 있다.

조합 확보 판정은 가중치 함수와 독립된 현행 11종 기준이다. 상처 6과 후속탄, 고압탄+저반동탄, 연계탄+고압탄/돌진탄의 세 방향을 사용한다. 반동 회복도 포함하는 넓은 조합 지표이므로 상처 방향은 별도 표시한다. 여러 방향을 가진 런은 방향별 분포에 균등 분할하며, 유효 방향 수는 그 분포의 엔트로피 지수다.

## 단독 준비탄 후속 획득

초기 재고를 고정하고 다섯 번까지 독립적인 제시 기회를 비교한다. 후속을 실제 선택하는 확률이 아니라, 준비를 개선하는 후보가 하나 이상 **제시되는** 확률이다. 평균 횟수는 5회 안에 성공한 경우만 포함한다. 절개는 탐험 11종·2지선다, 다른 세 행은 전체 탄약 도우미·3지선다이므로 행간 성공률을 직접 비교하지 않는다.

| 시작 재고 | 첫 기회 원래→약함→강함 | 5회 이내 원래→약함→강함 | 조건부 평균 기회 원래→약함 |
|---|---|---|---|
| 절개탄 1발 | 18.30→22.08→40.46% | 63.30→70.68→92.52% | 2.595→2.517 |
| 소이탄 1발 | 66.24→67.34→75.56% | 99.58→99.66→99.90% | 1.490→1.468 |
| 폭발탄 1발 | 30.84→38.96→62.20% | 83.96→91.88→99.16% | 2.282→2.125 |
| 고압탄 1발 | 37.98→48.10→77.12% | 91.28→96.08→99.98% | 2.113→1.881 |

소이탄의 차이는 작다. 복사·후속 강화 등 기존 대안도 유용한 후보에 포함되므로 한 종류의 전용 마무리 탄 출현 확률과 같지 않다. 등급 확률은 먼저 고정하므로 고급 탄이 많다는 이유로 고급 보상의 총량을 늘리지 않는다.

전체 탄약 실험의 첫 제시에서 관측한 고급 선택지 비율은 원래 25.11%, 약한 보정 24.98%, 강한 비교 25.08%다. 나머지는 일반 등급이다. 전체 탐험 선택지의 탄종별 출현 횟수도 원자료의 `offers`에 기록한다.

## 방향 전환과 포기

처음 확보한 완성 방향이 최종 재고에서 모두 사라지고 다른 완성 방향이 남으면 전환, 완성 방향이 하나도 남지 않으면 연결 상실로 센다. 거래가 없는 정책은 소유량이 줄지 않아 두 비율이 모두 0%다. 기존 연결을 유지하면서 다른 방향을 추가한 경우는 앞의 두 방향 이상 확보 지표에 포함한다.

| 실제 거래·고정 보상 수령 정책 | 원래 | 약한 보정 | 강한 비교 |
|---|---:|---:|---:|
| 최초 완성 방향을 잃고 다른 방향으로 전환 | 14.96% | 17.22% | 17.06% |
| 최초 완성 방향을 잃고 완성 방향이 남지 않음 | 14.32% | 10.72% | 4.82% |

첫 보상 뒤 절개탄을 가졌지만 최종 취약 연결 없이 다른 방향으로 끝난 조건부 비율은 거래 생략 정책에서 12.98→11.65→5.05%, 거래 정책에서 41.11→45.78→46.92%다. 비용을 지불한 전환 기회가 유지되며 초기 상태가 이후 선택을 강제로 고정하지 않는다. 이 수치는 정해진 선택 정책의 결과로, 실제 플레이어의 전략 변경 의도를 대신 측정하지는 않는다.

기존 v7의 18전투·제작·P220 상처 선호 정책을 사용하되 그 모델의 정의·`oriented` 판정으로만 비교했다. 생산 모델을 v7의 열 소비나 소작탄에 억지로 적용하지 않았다. 시뮬레이션에만 있는 어댑터가 기존 재고의 미완성 연결을 완성하는 후보 한 개를 같은 등급 안에서 보정한다.

## 남은 제약과 악용 가능성

- 직접 피해 쏠림의 근본 원인은 이 보정만으로 해결되지 않았다. 상처 빌드 확보율과 고립률 개선도 제한적이다. 탄약 피해나 정체성을 바꾸지 않고 그 한계를 남겼다.
- 처음 절개탄을 소유했으나 끝에 취약 연결이 없는 조건부 비율은 17.35→14.93→5.91%다. 이는 미완성·다른 방향 선택을 포함하는 결과 지표이며 플레이어의 의식적인 포기 행동을 측정한 것은 아니다. 거래로 완성 연결을 잃거나 다른 방향으로 전환한 횟수도 원자료에 별도 기록한다.
- 거래로 가진 탄을 지불하면 다음 전투의 가중치는 달라질 수 있다. 정상 비용을 지불하는 전략 변경이며 공짜 재추첨은 아니다. 현재 보상은 최초 표시 뒤 고정되고, 거래와 한도 검증도 유지된다.
- 같은 런 시드를 재시작하면 같은 지도와 상태에서 같은 보상을 볼 수 있다. 기존의 재현 가능한 시드 특성이며 새 런 간 결과 은닉 기능은 추가하지 않았다.
- 이 모델은 전투 최적화기가 아니다. 다중 턴·부착물·총기 특성의 숨은 연결을 놓칠 수 있다. 이번에 측정한 직접 피해 지표는 획득 구성의 대리 지표이며 실제 최적 피해의 우열이나 승률은 아니다.
