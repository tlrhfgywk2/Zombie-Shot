# 좀비 샷 탄약 배분과 전투 규칙

## 현재 범위

탄약을 직접 선택해 순서를 설계한다. 손패, 드로우, 버림 더미, 명중 확률은 없다. 보유 탄종은 스테이지 잔량이 남아 있는 동안 항상 선택할 수 있다. 총기·적 체력의 기존 규모와 장착물 조건, 충격에 의한 지연·노출 규칙을 기준으로 현실 탄약의 역할을 정리했다.

## 런 배분과 스테이지 잔량

- 표준탄은 상태에서 `'infinite'`로 표현하며 화면에는 `∞`를 표시한다. 특수 용량을 사용하지 않는다.
- 시작 배분은 확장탄 3발과 철갑탄 3발이다. 특수 용량의 임시 기본값은 6발이다.
- `Player.build`는 런 배분, `Player.stock`은 현재 스테이지의 미소비 잔량이다. 장전 중인 탄은 잔량에서 예약하되 아직 소비하지 않는다.
- 실제 발사 때 `fireRound`가 잔량을 한 번 차감한다. 장전 취소·교체·급탄기 용량 축소·적 사망으로 남은 탄은 소비되지 않는다.
- 같은 구간의 적 사이와 턴 사이에는 회복하지 않는다. 다음 구간 진입 시 `startStage`가 확정 배분으로 잔량을 재생성한다.
- `AMMO_BUILD_BALANCE`에 용량, 초기 배분, 기본/탄종별 보상량, 선택지 수, 등급 가중치를 모았다. 용량 증가는 `setSpecialCapacity`로 지원한다.

## 활성 탄약

명중 보정과 반동은 정확도 퍼센트포인트 단위다. 반동은 장착물 적용 전 탄약 자체 발생량이다.

| 탄약 | 등급 | 화력 | 명중 보정 | 반동 | 방어 파괴 | 충격 |
|---|---|---:|---:|---:|---:|---:|
| 표준탄 | 일반 | 22 | +0% | 7 | 0 | 0 |
| 확장탄 | 일반 | 30 | +0% | 9 | 0 | 0 |
| 철갑탄 | 일반 | 18 | +0% | 7 | 12 | 0 |
| 와드커터탄 | 일반 | 16 | +12% | 1 | 0 | 0 |
| 평두탄 | 일반 | 20 | +0% | 7 | 0 | 70 |
| 고압탄 | 고급 | 40 | -4% | 22 | 0 | 0 |
| 저소음탄 | 고급 | 19 | +3% | 0 | 0 | 0 |
| 본디드탄 | 고급 | 24 | +1% | 8 | 18 | 0 |
| 매치탄 | 고급 | 22 | +16% | 3 | 0 | 0 |

확장탄은 일반 등급의 무장갑 화력, 철갑탄은 방어 제거, 와드커터탄은 정밀도·후속 안정성, 평두탄은 충격을 담당한다. 고압탄은 높은 화력에 큰 후속 반동을 지불하며, 저소음탄은 반동 발생 0을 제공한다. 본디드탄은 방어 준비의 고급 선택지, 매치탄은 정확도 중심 선택지다. 소음·은신 시스템은 없다.

## 누적 반동과 피해

탄창마다 누적 반동 C를 0으로 시작한다.

1. 해당 탄의 정확도 = max(25, 100 + 탄약 명중 보정 + 활성 장착물 명중 보정 + 전투 불이익 − C). 상한은 없다.
2. 해당 탄의 피해를 계산하고 방어·충격·상태를 갱신한다.
3. 발생 반동 R = max(0, 총기 반동 0 + 탄약 반동 + 활성 장착물 반동 수정).
4. C에 R을 더한다. 다음 탄부터 이 누적값을 사용한다.

현재 탄의 반동은 자기 정확도를 바꾸지 않는다. 장착물 수정은 발생량에 한 번만 적용하고, 오염으로 봉쇄된 슬롯은 제외한다. 제동기와 손잡이로 발생량이 0이 될 수 있으며 음수 반동으로 정확도를 회복하지 않는다.

장착물 없는 근거리에서 와드커터 → 고압은 정확도 112%, 95%이고, 고압 → 와드커터는 96%, 90%다. 표준 → 표준 → 고압은 100%, 93%, 82%이고 고압 → 표준 → 표준은 96%, 78%, 71%다.

피해 D = round(화력 × 정확도/100 × 거리 배율 × 장착물 피해 배율 × 상태 배율).
근거리 4m 이하 ×1, 중거리 8m 이하 ×0.9, 그 밖은 ×0.72이다. 기존 초음파 사거리 불이익과 별도 배율도 동일 계산기에 적용한다.

## 방어와 방어 파괴

방어는 비율 감소가 아닌 소모되는 수치 자원이다.

1. 파괴 B = min(현재 방어, 탄약 방어 파괴). 방어에서 B를 제거한다.
2. 흡수 A = min(남은 방어, D). 방어에서 A를 제거한다.
3. 체력 피해 = min(현재 체력, D − A).

초과 방어 파괴는 버린다. 별도 관통 능력치나 장갑 상대 확장탄의 숨은 화력 감소는 없다. 계산 내역은 파괴 B와 흡수 A를 따로 보존한다. 표시되는 전체 방어 감소는 B+A다.

충격은 살아남은 적에게 누적한다. 임계 도달 시 다음 이동은 30%로 줄고, 예정된 특수 행동은 지연되며 다음 탄 하나는 노출 배율 1.4를 받는다. 노출은 적 행동 시 종료한다. 평두탄 2발의 충격 140은 일반·질주·장갑·거대·오염·공명 적의 임계를 넘지만, 지반 파쇄체의 145에는 미달한다.

## 보상과 구간

모든 구간 완료 시 세 가지 고유 탄약 보상을 제공한다. 등급을 일반 75 / 고급 25 가중치로 먼저 고르고 해당 등급 안에서 중복 없이 선택한다. 표준탄과 실험 탄약은 제외한다. 이미 소유한 탄종도 후보에 남으므로 집중 배분이 가능하다.

선택은 기본 1발의 런 배분을 추가한다. 여유 용량이 있으면 즉시 반영한다. 가득 찼다면 교체할 기존 배분을 플레이어가 직접 고른다. 선택한 탄종과 같은 탄종의 배분을 교체하는 유지 선택도 허용한다. 보상량을 늘린 경우 필요한 수만큼 선택한 뒤 원자적으로 반영한다. 교체 화면에서 보상을 다시 고를 수 있다.

구간 완료 → 보상 → 필요 시 배분 교체 → 다음 경로 선택 → 구간 진입 및 회복 순이다. 마지막 구간도 보상을 확정한 뒤 승리를 표시한다. 일반·특수 경로의 탄약 보상 규칙은 같다. 특수 경로는 여러 적 대신 단일 특수 행동 적과 싸우는 선택이다.

| 구간 | 일반 경로 | 특수 경로 |
|---|---|---|
| 1 외곽 골목 | 일반 ×2, 모두 방어 0 | 없음 |
| 2 붕괴된 교차로 | 일반·질주, 모두 방어 0 | 오염: 체력 215 / 방어 8 |
| 3 장갑 검문소 | 장갑: 체력 82 / 방어 18 + 일반 | 지반: 체력 210 / 방어 24 |
| 4 공명 지하도 | 질주 + 장갑 | 공명: 체력 195 / 방어 0 |
| 5 최종 방어선 | 거대: 체력 126 / 방어 0 + 질주 + 장갑 | 지반: 체력 210 / 방어 24 |

방어는 적 정의에 두고 구간별 편성으로 분포를 조절한다. 일반 경로에서는 3구간에, 특수 경로에서는 2구간에 방어를 소개한다. 후반에도 무장갑 고체력 적과 혼합 무리를 유지한다. 장갑 적도 표준탄만으로 처치 가능하다.

## 프리뷰와 화면

`Game.syncMagazine`와 실제 사격은 같은 `CombatResolver.resolveSequence`를 호출한다. 적 체력·방어·거리·상태와 현재 장착물을 입력하므로 뒤쪽 탄은 앞선 탄이 갱신한 방어/노출/반동을 반영한다. 처치 후 탄은 정확도를 임의로 예측하지 않고 미발사로 표시한다.

탄약 카드에는 이름·등급·스테이지 잔량/런 배분·장전 예약과 다섯 수치를 직접 표시한다. 소유하지 않은 탄종은 기본 랙에서 숨긴다. 늘어난 카드 목록은 가로로 스크롤한다. PC와 세로 화면 모두 탄별 정확도와 최종 체력·방어·피해 프리뷰를 유지한다. 전투 장면과 준비 패널은 별도 행이며 진단 요소는 `?presentationDebug=1` 뒤에 유지한다.

## 보존한 실험 코드

열화·빙결·전도·새벽서약·핏빛각인과 이전 압력·중량 탄약의 정의는 `dormantAmmoDefinitions.ts`에 분리했다. 상태 축적 및 회수 계산은 회귀 위험을 줄이기 위해 남겼다. 활성 `AMMO_ORDER`, 시작 배분, 보상, 기본 탄약 랙에는 포함하지 않는다. 원소 촉매관·회수 급탄기·심연 각인·백묵 서약 손잡이도 일반 장착물 목록에서 제외했다. 상태 시스템의 기존 회귀 테스트는 실험 정의를 직접 사용한다.

## 검증과 밸런스 한계

자동 테스트는 런 배분, 실제 발사 소비, 미발사·장전 예약, 구간 회복, 보상 중복/가중치/교체, 누적 반동, 방어 순서, 충격 역할, 정확도 100% 초과, 프리뷰 일치와 기존 표현 회귀를 확인한다.

현실 탄약 전용 밸런스 표본은 6개 전략 × 4개 장착 구성 × 7종 적 = 168개 단일 조우와 6개 전략 × 4개 구성 × 16개 경로 = 384개 전체 런이다. 단일 조우는 전략별 시험 배분, 전체 런은 실제 시작 배분 3+3과 보상 선택을 사용한다. 두 표본의 의미를 혼동하지 않는다. 이전 원소/신화 전략의 승률과 장착물 지배율은 새 설계에 유효하지 않아 폐기했다.

보상은 시드 난수로 재현하고 전투는 결정론적이다. `npm run test:balance`에서 현재 표본 보고서를 출력한다. 이 표본은 최적 플레이나 모든 보상 운을 대표하지 않는다. 6발 용량은 임시값이며, 방어 파괴 탄의 집중 효율, 반동을 모두 상쇄하는 장착물 구성, 후반 특수 적 난도는 후속 조정 대상으로 남는다.
