# 좀비 샷 탄약 배분과 전투 규칙

## 현재 범위

서비스 .45와 활성 탄약 9종으로 탄약 선택, 발사 순서, 적 행동 중단을 설계한다. 무작위 빗나감, 치명타, 새 자원 미터는 없다. 원소·신화 탄약은 진행과 보상에서 제외된 실험용 데이터다.

## 배분과 소비

표준탄은 무한 공급이다. 시작 배분은 확장탄 3발·철갑탄 3발, 특수 용량은 14발이다. 탄창은 기본 4발이며 장착물로 최대 6발이다. 장전은 예약이고 실제 발사한 특수탄만 소비한다. 처치 후 남은 탄, 취소한 탄, 용량 축소로 빠진 탄은 소비하지 않는다. 같은 구간에서는 잔량을 유지하고 다음 구간에서 배분만큼 회복한다.

## 활성 탄약

| 탄약 | 등급 | 기본 화력 | 방어 파괴 | 충격 | 조건·순서 특성 |
|---|---|---:|---:|---:|---|
| 표준탄 | 일반 | 4 | 0 | 0 | 무한 공급 |
| 확장탄 | 일반 | 4 | 0 | 0 | 사격 시작 시 무장갑이면 화력 +3 |
| 철갑탄 | 일반 | 3 | 4 | 0 | 장갑 제거 준비 |
| 와드커터탄 | 일반 | 3 | 0 | 2 | 지속 충격 축적 |
| 평두탄 | 일반 | 4 | 0 | 5 | 충격 포화 |
| 고압탄 | 고급 | 8 | 0 | 0 | 강한 반동 |
| 저소음탄 | 고급 | 4 | 0 | 0 | 안정 |
| 본디드탄 | 고급 | 5 | 5 | 0 | 사격 시작 시 무장갑이면 화력 -2 |
| 매치탄 | 고급 | 3 | 0 | 0 | 거리 손실 15%p 완화, 강한 반동 직후에는 비활성 |

## 충격과 적 행동

충격(`actionShock`)은 적에게 남는 정수 자원이다. 자동 감소가 없고 임계치 미만이어도 보존한다. 원소 전하의 `shock` 식별자와 구분한다. 충격은 속도·거리·화력·방어 파괴를 바꾸지 않으며 노출 상태를 만들지 않는다.

적은 한 턴에 한 가지 주 행동만 선택한다. 거리 0이면 치명 공격, 그렇지 않고 특수 행동이 도래했으면 해당 특수 행동, 나머지는 접근이다. 행동 직전 충격이 임계치 이상이면 정확히 임계치만 소비하고 행동 전체를 중단한다. 부족하면 소비 없이 실행한다.

| 행동 | 기본 임계치 |
|---|---:|
| 접근 | 4 |
| 치명 공격 | 8 |
| 오염 투척 | 6 |
| 지반 충격 | 7 |
| 초음파 공명 | 6 |

일반 +0, 장갑 +1, 질주 -1, 거대 +2, 오염 +1, 지반 +2, 비명 +1의 저항을 더한다. 최종 임계치는 최소 1이다. 임계치는 `CombatResolver.ACTION_SHOCK_THRESHOLDS`, 저항은 `enemyDefinitions`에서 조정한다.

접근으로 거리 0에 도착해도 패배하지 않는다. 다음 장전 턴에 처치하거나 충격으로 치명 공격을 막을 수 있다. 치명 공격을 중단하면 적은 거리 0에 남는다. 실제 치명 공격이 해결될 때만 패배한다.

특수 행동은 접근을 대체한다. 실행과 충격 중단 모두 재사용 대기를 정상 초기화하며 중단한 행동은 즉시 재시도하지 않는다. 카운트다운 갱신은 별도 행동이 아니다.

- 오염 투척: 장착된 슬롯 하나를 2턴 봉쇄한다.
- 지반 충격: 2개 플레이어 턴 동안 강한 반동의 후속 화력 페널티가 -2에서 -3이 된다. 해당 조합을 쓰지 않으면 그대로 만료된다.
- 초음파 공명: 2턴 동안 유효 거리 단계를 하나 악화한다.

## 탄창 안의 순서 특성

강한 반동은 바로 다음 탄의 직접 화력을 2 낮추고 소멸한다. 안정탄은 페널티 없이 흡수한다. 방어 파괴와 충격은 영향받지 않는다. 마지막 발의 강한 반동은 다음 턴으로 넘어가지 않는다.

충격 포화는 바로 다음 탄에 충격이 있으면 그 충격을 2 낮춘다(최소 0). 충격 없는 탄이면 그대로 소멸한다. 평두 → 와드는 충격 5·0, 평두 → 표준 → 와드는 5·0·2다. 평두 → 평두 → 와드는 5·3·0이며 각 평두탄은 자기 다음 탄에 새 포화를 설정한다.

두 상태는 `resolveSequence` 지역 변수다. 현재 탄의 수정치를 먼저 계산한 뒤 장갑·피해·생존한 적의 충격을 처리하고 다음 탄의 특성을 설정한다. 발사 자체가 적을 접근시키는 규칙은 없다.

## 화력·거리·장갑

사격 시작 시 장갑 조건과 직전 탄 페널티를 반영한다. 무기·탄약·장착물·상태의 직접 화력을 합산한 뒤 거리 손실을 한 번 적용하고 .5 올림 최근접 정수로 반올림한다. 최종 화력은 최소 1이다. 서비스 .45의 근·중·원거리 손실은 0%·10%·25%다. 방어 파괴와 충격에는 거리 배율을 적용하지 않는다.

방어 파괴를 먼저 적용하고 남은 장갑이 화력을 흡수한다. 방어 파괴 탄은 같은 발에서 파괴와 흡수로 장갑을 중복 소모하지 않는다. 초과 파괴량은 체력 피해가 되지 않는다. 확장탄은 자신이 장갑을 소모해도 같은 발의 무장갑 보너스를 받지 않는다.

## 장착물 이전

기존 반동 감소 장착물은 총기 흔들림 연출 감소로 이전했다. 기존 비율과 거리·최근접·봉쇄 조건을 유지하되 화력 페널티나 적 거리에 영향을 주지 않는다. 장착물 화면에도 연출 효과임을 표시한다. 탄창 용량과 조준기의 거리 완화는 기존 전투 효과를 유지한다. 이로 인해 연출 전용 장착물의 보상 가치가 낮아진 점은 후속 장착물 설계 과제다.

## 프리뷰와 검증

선택과 실제 사격은 모두 `CombatResolver.resolveSequence`를 사용한다. 프리뷰는 실제 발사할 탄의 피해·장갑·충격과 인접 탄 효과를 표시하며 처치 뒤 미발사 탄은 구분한다. 다음 적 행동은 동일한 `resolveEnemyAction`으로 예측한다. 확정 처치에는 적 행동이 없다.

적 카드에는 현재 충격, 다음 행동과 임계치, 중단 시 예상 잔여량을 표시한다. 탄창 슬롯에는 수정된 화력과 충격, 반동·안정·포화 적용을 표시한다. 진단 표식은 계속 `?presentationDebug=1`에서만 표시한다.

수치상의 한계와 검증 결과는 [충격·순서 개편 기록](ACTION_SHOCK_REWORK.md)을 참고한다. 이전 [반동·거리 기록](RECOIL_DISTANCE_REWORK.md)은 대체된 역사 문서다.
