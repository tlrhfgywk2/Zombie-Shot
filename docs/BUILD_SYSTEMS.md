# 좀비 샷 탄약 배분과 전투 규칙

## 현재 범위

탄약을 직접 선택해 발사 순서를 설계한다. 손패, 드로우, 버림 더미, 무작위 빗나감은 없다. 현재 플레이 가능한 총기는 서비스 .45 한 종이며, 탄약 선택과 순서가 전투의 중심이다.

## 런 배분과 스테이지 잔량

- 표준탄은 무한 공급이며 특수 용량을 사용하지 않는다.
- 시작 배분은 확장탄 3발과 철갑탄 3발, 특수 용량은 14발이다.
- 장전은 예약이다. 실제 발사한 특수탄만 현재 스테이지 잔량에서 차감한다.
- 적 사망·접근 돌파 뒤 미발사 탄, 장전 취소, 용량 축소로 밀려난 탄은 소비하지 않는다.
- 같은 구간의 적 사이에는 잔량을 유지하고 다음 구간 진입 시 런 배분만큼 회복한다.

화력 수치와 체력·방어·방어 파괴·충격·상태 수치는 작은 정규화 규모를 유지한다. 매치탄만 테마에 맞게 거리 손실을 10%p 완화하며, 다른 탄약의 화력이나 특수 효과를 대신 올리지 않는다.

## 직접 화력과 거리

직접 화력은 다음 순서로 계산한다.

1. 무기·탄약·활성 장착물·상태·특수 적 화력 항을 합산한다.
2. 실제 거리 단계와 거리 악화 효과를 결정한다.
3. 서비스 .45의 근거리 0%, 중거리 10%, 원거리 25% 손실에서 명시적 완화 퍼센트포인트를 뺀다.
4. `직접 화력 × (1 - 거리 손실 / 100)`을 계산한다.
5. 양의 결과를 최근접 정수로 반올림하며 정확히 `.5`면 올린다. 유효 사격은 최소 화력 1이다.
6. 정수 화력으로 방어와 체력을 처리한 뒤, 방어 파괴·충격·상태 축적 같은 독립 효과를 기존 수치 그대로 처리한다.

거리 손실은 직접 화력에만 한 번 적용한다. 방어 파괴, 화상 피해, 충격, 축적량을 곱하지 않는다.

## 누적 반동과 재조준

탄창 발사 시퀀스마다 누적 반동 `C`를 0으로 시작한다. 각 탄의 반동은 현재 탄의 피해를 바꾸지 않고 발사 직후 `C`에 더해진다. 적이 살아 있으면 마지막 탄을 포함해 각 사격 후 자세 회복 중 다음만큼 접근한다.

```text
추가 접근 = 적의 평소 한 턴 이동 × 0.01 × 발사 후 누적 반동
```

문턱이나 단계는 없다. 반동 2는 같은 적에게 반동 1의 두 배 접근을 만든다. 처치한 탄에는 접근이 없으며, 탄창 시퀀스가 끝나면 누적값은 폐기되고 다음 발사 시퀀스는 다시 0에서 시작한다.

장착물 반동 감소는 각 비율을 남은 반동에 곱한다. 예를 들어 고압탄 반동 2에 이중 포트 보정기 35%와 G10 손잡이 25%를 쓰면 `2 × 0.65 × 0.75 = 0.975`가 된다. 여러 장착물을 써도 반동을 0으로 만들지 않는다. 지반 충격은 탄약 반동을 2턴 동안 50% 늘리며, 원래 반동이 0인 탄은 영향을 받지 않는다.

## 방어·충격·상태

방어 파괴는 먼저 현재 방어에서 제거한다. 남은 방어가 최종 화력을 흡수한다. 방어 파괴 탄은 같은 한 발에서 파괴와 흡수로 방어를 중복 소모하지 않으며 초과 파괴량은 체력 피해가 되지 않는다.

충격 임계는 다음 이동과 특수 의도를 늦추고 다음 탄 하나에 노출 화력 보너스를 준다. 화상·냉기·전하·침식은 각 축적 임계와 기존 독립 효과를 유지한다.

## 프리뷰와 검증

`Game.syncMagazine`와 실제 사격은 모두 `CombatResolver.resolveSequence`를 사용한다. 프리뷰의 피해, 방어, 충격, 반동 접근과 실제 상태 변화는 같은 결과 객체에서 나온다. 화면의 다음 접근은 연속 사격 중 반동 접근과 이후 적 행동 이동을 합친 값이다.

자동 검증은 재고·예약·소비·보상·경로, 세 거리 단계, 전역 반올림, 누적 반동의 선형성·초기화, 접근 중복 방지, 장착물 조건, 방어·방어 파괴·화상·충격·상태 회귀를 확인한다. 상세 수치 표본은 [반동·거리 개편 기록](RECOIL_DISTANCE_REWORK.md)에 있다.

표시 진단은 계속 `?presentationDebug=1` 뒤에만 존재한다.
