# 소수 전투 수치 정규화 기록

이 문서는 전투 수치를 작은 정수 규모로 낮춘 작업의 현재 유효 원칙만 보존한다. 최신 반동·거리 규칙과 수치 근거는 [반동·거리 개편 기록](RECOIL_DISTANCE_REWORK.md)을 따른다.

## 유지하는 원칙

- 무기·탄약 화력, 적 체력·방어, 방어 파괴, 충격, 화상과 축적량은 작은 수치를 유지한다.
- 방어 파괴를 먼저 적용하고 남은 방어가 정수 직접 화력을 흡수한다.
- 초과 방어 파괴는 체력 피해로 바뀌지 않는다.
- 충격·노출과 상태 축적은 탄약 순서의 보상을 만든다.
- 별도 관통 수치나 무작위 빗나감은 없다.
- 거리만 직접 화력에 고정 퍼센트 손실을 적용하며 결과는 전역 규칙으로 정수화한다.
- 반동은 피해를 바꾸지 않고 생존한 적에게 각 사격 후 추가 접근만 만든다.

## 현재 대표 수치

- 일반 감염체: 체력 22, 시작 거리 8m, 한 행동 이동 2m.
- 서비스 .45: 무기 화력 항 0, 탄창 4발, 거리 손실 0%·10%·25%.
- 표준탄: 화력 4, 반동 1.
- 확장탄: 화력 6, 반동 1.
- 철갑탄: 화력 3, 반동 1, 방어 파괴 4.
- 고압탄: 화력 8, 반동 2.
- 화상: 행동마다 피해 3, 2회.

큰 초기 수치나 연속 곱셈 모델로 되돌리지 않는다.
