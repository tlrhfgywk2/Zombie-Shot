# 정수 전투 리밸런스 기록

## 원인과 이전 계산 경로

이전 구현에는 무기 기본 화력이 없었고 탄약의 `directDamage`가 사실상 한 발의 전체 기본 피해였다. 한 발의 정확도는 기본값 100에 탄약·부착물·적 방해·누적 반동을 더한 값이었으며, 음수 탄약 정확도와 반동에는 부착물 소수 배율을 곱했다. 거리에는 별도 소수 배율과 초음파 배율, 반사 조준기의 중거리 회복분이 연결됐다. 마지막으로 탄약 피해에 정확도·거리·상태·특수 적 배율을 연속 곱하고 반올림했다.

```text
이전 직접 피해 = round(탄약 피해 × 정확도 비율 × 거리 배율 × 상태/특수 배율)
```

이 구조는 플레이어가 탄약 화력만 보고 실제 결과를 계산하기 어렵게 만들었다. `attachmentMultiplier = 1`과 사용하지 않는 사격 문맥 필드도 남아 있었다. 별도 관통 능력치는 원래 존재하지 않았고, 철갑/본디드 탄약의 역할은 방어 파괴였다.

## 최종 규칙

```text
정확도 = 무기 정확도 + 보정된 탄약 정확도 + 장착물 정확도 + 적 방해 - 누적 반동

최종 화력 = max(1,
  무기 기본 화력
  + 탄약 화력
  + 장착물 화력
  + 정확도
  - 거리 페널티
  + 상태 화력 보너스
  + 특수 적 화력 보너스)
```

모든 직접 화력 항은 정수다. 정확도는 확률이나 배율이 아니며 최종 화력에 그대로 더한다. 서비스 .45의 기본 화력은 2, 정확도는 0, 반동은 0, 거리 페널티는 근거리 0·중거리 1·원거리 2다. 초음파는 유효 거리 단계를 하나 악화하고 반사 조준기는 실제 중거리 페널티를 1 줄인다.

방어 해결 순서는 유지한다. 방어 파괴량을 먼저 제거하고 남은 방어가 최종 화력을 흡수한다. 방어 파괴 탄은 같은 한 발에서 파괴와 흡수로 방어를 중복 소모하지 않는다. 초과 방어 파괴는 체력 피해가 되지 않는다. 별도 관통 능력치는 추가하지 않았다.

노출은 다음 탄 화력 +3, 침식은 희귀 이상 탄약에 화력 +2, 새벽서약탄은 특수 적에게 화력 +3이다. 열기 축적은 4에서 발동하며 열화탄은 2씩 축적한다. 화상은 적 행동마다 3 피해를 2회 준다. 피해 배율은 남아 있지 않으며 충격/둔화의 이동 배율만 물리적 접근 속도 규칙으로 유지한다.

## 무기 전후

현재 플레이 가능한 권총은 한 종이다.

| 무기 | 이전 기본 화력 | 최종 기본 화력 | 이전 정확도 | 최종 정확도 | 이전 거리 | 최종 거리 페널티 |
|---|---:|---:|---:|---:|---|---|
| 서비스 .45 | 없음 | 2 | 기본 100 기준 | 0 | 근/중/원거리 배율 | 0 / 1 / 2 |

## 대표 전투 표본

| 사례 | 결과 |
|---|---|
| 서비스 .45 + 표준탄, 중거리 | 2 + 4 + 0 - 1 = 화력 5 |
| 서비스 .45 + 고압탄, 중거리 | 2 + 8 - 1 - 1 = 화력 8 |
| 정확한 매치탄, 원거리 | 2 + 3 + 2 - 2 = 화력 5 |
| 부정확한 고압탄, 원거리 | 2 + 8 - 1 - 2 = 화력 7, 반동 2 |
| 철갑→확장, 장갑 감염체 | 체력 피해 6, 방어 5 제거 |
| 확장→철갑, 장갑 감염체 | 체력 피해 3, 방어 5 제거 |
| 표준탄, 장갑 감염체 첫 발 | 화력 4를 방어가 모두 흡수, 체력 피해 0 |
| 열화탄 2발, 원거리 | 직접 피해 6 + 다음 두 행동 화상 6 |
| 정확도 장착물 3개 + 표준탄, 근거리 | 2 + 4 + 3 = 화력 9 |

168개 단일 조우와 384개 전체 경로 시뮬레이션에서 일반·장갑·질주·거대 적 표본 승률은 모두 100%였다. 특수 적은 전략/장착 구성에 따라 75–95.8%, 전략별 전체 경로 완주율은 76.6–81.3%였다. 무장착 표준탄의 처치 발수는 일반 6, 질주 5, 장갑 10, 거대 13, 특수 적 12다. 표준탄은 모든 적을 처치할 수 있지만 방어 준비와 탄약 시너지가 더 효율적이다. 활성 탄약의 첫 발은 일반 감염체를 즉시 처치하지 않는다.

## UI와 검증 기준

탄약 카드와 툴팁은 `화력 / 정확도 / 반동 / 방어 파괴 / 충격` 정수를 표시한다. 탄약 랙은 서비스 .45 기본 화력 2를, 거리 카드는 현재 거리 화력 페널티를 표시한다. 기존 탄창 프리뷰는 정확도·거리 페널티·최종 화력을 정수로 표시하지만 새로운 탄별 결과 예측 화면은 추가하지 않았다. 물리적 거리와 이동 거리는 미터 단위이므로 소수 한 자리 표시를 유지한다.

규칙 테스트는 공식, 정확도, 거리 3단계, 최소 화력, 방어 0, 방어 완전 파괴, 무관통 방어 흡수, 화상 타이밍, 충격/노출, 정확도 장착물 중첩, 정확히 0 HP 사망, 다중 탄창 순서를 검증한다. 모든 탄약/무기/부착물/적의 조정 가능한 직접 전투 수치가 정수이고 폐기 필드가 남지 않았는지도 검사한다.
