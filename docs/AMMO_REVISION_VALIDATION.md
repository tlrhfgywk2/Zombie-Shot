# 탄약 시스템 개편 검증 기록

이 문서는 초기 탄약 배분 개편의 역사적 범위만 남긴다. 당시의 전투 수치와 공식은 2026년 정수 전투 리밸런스에서 폐기되었으므로 현재 구현의 근거로 사용하지 않는다. 최신 규칙과 검증 기준은 [빌드 시스템 문서](BUILD_SYSTEMS.md)와 [정수 전투 리밸런스 기록](INTEGER_COMBAT_REBALANCE.md)을 따른다.

초기 개편에서 확립되어 현재도 유지하는 규칙은 다음과 같다.

- 표준탄은 무한 공급이고 특수탄은 런 배분과 스테이지 잔량을 분리한다.
- 장전은 예약이며 실제 발사한 특수탄만 소비한다.
- 적 사망 뒤 미발사 탄과 조건부 회수탄은 소비하지 않는다.
- 같은 구간의 적 사이에는 잔량을 유지하고 다음 구간 진입 시 배분만큼 회복한다.
- 방어 파괴는 일반 피해 흡수보다 먼저 처리하고 초과 파괴량은 체력 피해로 바꾸지 않는다.
- 충격·상태 축적·부착물 봉쇄·탄약 순서는 결정론적으로 처리한다.
- 화면 프리뷰와 실제 사격은 같은 `CombatResolver` 계산을 사용한다.

현재 자동 검증은 재고·예약·소비·보상·교체·경로 흐름과 함께 정수 정확도, 정수 거리 페널티, 최소 화력, 방어, 방어 파괴, 화상, 충격, 상태 순서를 검사한다. 데스크톱과 세로 화면의 최신 렌더링 결과는 각 변경의 PR 및 현재 배포를 기준으로 확인한다.
