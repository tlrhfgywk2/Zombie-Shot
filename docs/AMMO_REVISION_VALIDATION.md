# 탄약 시스템 개편 검증 기록

이 문서는 최초 개편 당시 용량 6발의 검증 기록이다. 이후 특수 적재 용량은 14발로 변경됐다. 현재 규칙은 [빌드 시스템 문서](BUILD_SYSTEMS.md)를 따른다.

## 기준과 범위

- 작업 시작 시 원격 develop: `02918ff210ecf4aaf8708284f843ae6dfd30ffd3`. 기준 이후 추가 커밋은 없었으며 작업 폴더는 깨끗했다.
- 탄약·사격·장전·플레이어·적·구간·경로·프리뷰·표현·장착물·시뮬레이션 및 관련 테스트를 확인했다.
- 탄약의 관통 능력치, 기존 방어 파괴 필드, 인덱스 반동, 누적 보급, 등급·원소 탄약 참조를 검색해 정리했다.
- 활성 수치와 공식의 기준은 [빌드 시스템 문서](BUILD_SYSTEMS.md)와 코드의 데이터 정의다.

## 자동 검증

- Vitest 15개 파일, 112개 테스트 통과.
- ESLint 통과.
- TypeScript 전체 타입 검사 통과.
- Vite 프로덕션 빌드 통과.
- 재고·예약·발사·미발사·0 잔량·구간 회복·배분 용량·같은 탄종 집중·명시 교체·보상량 변경·재시작 회귀를 검증했다.
- 게임 컨트롤러를 실제로 실행하고 표현 계층만 모의 처리한 통합 테스트로 적 사이 소비 유지, 보상 취소, 제시하지 않은 보상 거절, 중복 선택 거절, 다음 경로 진입과 회복을 검증했다.
- 무장갑/방어/초과 파괴/충격/노출/누적 반동/봉쇄된 장착물/100% 초과 정확도/프리뷰와 순차 계산 일치를 검증했다.
- 보상 10,000회 시드 표본으로 첫 선택의 일반 비율이 73~77% 범위인지 검증했다. 매 화면은 세 가지 고유 현실 탄약이다.

## 실제 렌더링과 조작

로컬 Chrome에서 게임 화면과 버튼을 조작했다. 데스크톱 1440×900과 세로 390×844 스크린샷을 직접 확인했다. 세로 화면에서도 정확한 탄약 수치, 탄별 정확도, 체력·방어 프리뷰를 읽을 수 있었고, 전투 장면과 준비 패널은 분리돼 있었다.

일반 경로를 정상 시작 배분으로 5구간 모두 플레이했다. 보상 5회 모두 선택 후 기존 배분을 직접 교체했으며 마지막 보상 확정 후 승리를 확인했다. 런타임 오류는 없었다.

- 시작: 표준 ∞, 확장 3/3, 철갑 3/3.
- 첫 표적에 확장·확장·확장·철갑을 예약했다. 확장 3발로 처치한 뒤 두 번째 표적에서 확장 0/3, 철갑 3/3을 확인했다. 미발사 철갑은 소비되지 않았다.
- 확장 0/3 선택 불가, 표준 ∞ 유지, 같은 구간 회복 없음, 다음 구간 진입 후 새 배분의 모든 잔량 회복을 확인했다.
- 실제 획득한 탄종은 와드커터, 매치, 평두, 고압이었다. 배분 6발을 유지하면서 철갑 또는 확장 배분을 교체했다.
- 3구간 장갑 표적: 방어 18 / 체력 82에서 철갑·확장·확장·확장의 프리뷰는 체력 피해 56, 남은 체력 26 / 방어 0이었다. 실제 사격 뒤 체력 26 / 방어 0과 일치했다.
- 후반의 일반·질주·거대 적은 방어 0, 장갑 적은 방어 18로 혼재했다. 특수 경로 분포는 데이터 검사와 전체 경로 시뮬레이션으로 추가 확인했다.
- 마지막 구간에서 특수탄을 소진한 뒤 표준탄으로 질주·장갑 적을 계속 처치하고 완주했다.

## 순서 비교 시나리오

브라우저의 별도 시험 페이지에서 실제 Game/Player/CombatResolver/UI를 불러왔다. 배분 API로 와드커터·고압을 준비하고 장착물을 해제했다. 이 설정 코드는 임시 외부 검증 파일이며 일반 게임에 시험 훅을 추가하지 않았다. 이후 장전·발사는 실제 세로 UI의 터치 조작으로 수행했다.

| 표적/순서 | 정확도 | 실제 체력 피해 | 프리뷰 일치 |
|---|---|---:|---|
| 일반 76, 거리 8m / 와드 → 고압 | 112%, 95% | 50 | 체력 26 |
| 일반 76, 거리 8m / 고압 → 와드 | 96%, 90% | 48 | 체력 28 |
| 장갑 82/방어18, 거리 9m / 철갑 → 확장 | 100%, 93% | 27 | 체력 55 / 방어 0 |
| 장갑 82/방어18, 거리 9m / 확장 → 철갑 | 100%, 91% | 16 | 체력 66 / 방어 0 |

네 시나리오 모두 실제 결과와 프리뷰가 일치했고 런타임 오류가 없었다.

## 집중 밸런스 표본

168개 단일 조우에서 일반·장갑·질주·거대 적 승률은 각각 100%, 오염 95.8%, 지반 66.7%, 공명 87.5%였다. 384개 전체 런에서 모든 경로 조합에 완주 가능한 구성이 있었다.

| 전략 | 전체 런 완주율 |
|---|---:|
| 표준탄 기준 | 54.7% |
| 방어 준비 | 59.4% |
| 화력 우선 | 70.3% |
| 안정 선행 | 67.2% |
| 정밀 사격 | 65.6% |
| 충격 연계 | 62.5% |

고정 휴리스틱 전략의 비교 표본이며 최적 플레이 승률은 아니다. 현재 임시 용량 6발과 강한 반동 상쇄 장착물, 후반 지반 파쇄체 난도는 후속 플레이 데이터를 보고 조정할 수 있다. 실제 휴대전화 하드웨어 검증은 수행하지 않았다.
