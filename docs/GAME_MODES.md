# 게임 모드와 초기 탄약

시작 화면에는 **프리 모드**와 **탐험 모드** 두 선택지만 표시한다. 기존 초기 탄약 지급은 프리 모드에 합쳤다. 두 모드 모두 권총 선택 카드에서 지급 탄약의 이름·그림·수량을 확인할 수 있다.

| 권총 | 무제한 | 지급 특수탄 |
| --- | --- | --- |
| P220 | 표준탄 | 초탄 ×1, 평두탄 ×2 |
| M1911 9mm | 표준탄 | 종결탄 ×1, 절개탄 ×2 |
| 데저트 이글 | 표준탄 | 고압탄 ×1, 저반동탄 ×2 |
| S&W M500 | 표준탄 | 경량장전탄 ×1, 연계탄 ×1 |

초기 지급은 `src/data/gameModes.ts`에서 관리한다. 다른 특수탄은 0발로 시작한다. 프리 모드는 체력 10000의 기존 훈련 표적과 자유로운 탄약·부착물 추가 및 제거를 제공한다. 탐험 모드에는 수동 보급 버튼을 표시하지 않으며 게임 제어에서도 수동 보급을 거부한다. 탐험 보상·이벤트·거래로만 보유량을 바꾼다.

## 소유량과 잔량

- `Player.build`: 런 동안 유지하는 소유량. 실제 발사로 줄어들지 않는다.
- `Player.stock`: 현재 조우에서 사용 가능한 잔량. 발사한 특수탄만 줄어든다.
- 장전은 예약이다. 제거·교체·순서 이동과 조기 처치로 미발사된 탄은 소비하지 않는다.
- 같은 조우의 다음 탄창에서는 소모한 특수탄이 돌아오지 않는다.
- 두 모드 모두 감염체 처치 또는 패배 시 `endEncounter()`로 현재 소유량에 맞춰 잔량을 복구한다.
- 거래로 영구 지불한 탄약은 소유량과 잔량에서 함께 제거한다. 조우 종료와 다음 구간에서 복구되지 않는다.
- 수동 보급, 탐험 보상, 휴대 한도, 획득 부착물은 런 동안 유지한다. 부착물은 기존 전투 준비 UI에서 직접 장착한다.

다시 시작은 모드와 권총을 유지하며 최초 지급량·빈 탄창·기본 휴대 한도·미보유 부착물로 돌아간다. 탐험은 입구와 장비 선택부터 다시 시작한다. 모드 선택으로 돌아가면 이전 런의 진행·재고·정보 장비를 모두 비운다. 장전·사격·실린더 선택 중에는 전환할 수 없다.

탐험의 진행·정보 도구·이벤트·상인·생존 가정은 [탐험 프로토타입 규칙](탐험_프로토타입.md), 실제 렌더링과 검증 결과는 [검증 기록](validation/exploration/검증기록.md)에 정리한다.
