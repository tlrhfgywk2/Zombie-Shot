# 게임 모드와 초기 탄약

실행하면 모드 선택 → 기존 권총 선택 → 전투 준비 순서로 진입한다. 초기 탄약 지급 모드의 권총 카드에는 무제한 표준탄과 지급 특수탄의 이름·그림·수량을 표시한다. 보유 탄약 확인과 자유로운 탄창 배열은 기존 UI를 사용한다.

| 권총 | 무제한 | 지급 특수탄 |
| --- | --- | --- |
| P220 | 표준탄 | 초탄 ×1, 평두탄 ×2 |
| M1911 9mm | 표준탄 | 종결탄 ×1, 절개탄 ×2 |
| 데저트 이글 | 표준탄 | 고압탄 ×1, 저반동탄 ×2 |
| S&W M500 | 표준탄 | 경량장전탄 ×1, 연계탄 ×1 |

다른 특수탄은 모두 0발이다. `src/data/gameModes.ts`의 중앙 설정을 초기화와 미리보기가 함께 사용한다. 프리 모드는 기존 `createAmmoBuild()`의 초기 배분과 수동 보급·제거·부착물 시험 기능을 그대로 사용한다. 기존 수동 보급 도구는 두 모드에서 사용할 수 있다.

## 탄약의 소유와 잔량

- `Player.build`: 런 동안 유지하는 보유량. 실제 발사로 줄지 않는다.
- `Player.stock`: 현재 조우의 잔량. 실제 발사한 특수탄만 줄어든다.
- 장전은 예약이며 제거·교체·순서 이동과 조기 처치로 미발사된 탄은 소비하지 않는다.
- 같은 조우에서 탄창을 다시 준비해도 소모한 특수탄이 돌아오지 않는다.
- 초기 탄약 모드는 감염체 처치 또는 패배 때 `endEncounter()`가 현재 보유량으로 잔량을 복구한다. 이후 감염체 생성·경로 전환에서도 최초 지급표를 다시 적용하지 않는다.
- 수동 보급·영구 제거와 기존 보상 API에 반영된 탄약, 휴대 용량, 부착물은 복구 후에도 유지한다.
- 프리 모드는 기존 구간 시작의 잔량 복구 규칙을 유지한다.

초기 지급은 `startRun()`에서 한 번 적용한다. 다시 시작은 현재 모드와 권총을 유지하면서 초기 배분·빈 탄창·기본 휴대 용량·미보유 부착물로 돌아간다. 모드 선택으로 돌아가면 이전 런을 비우고 새 모드와 권총을 고른다. 장전·사격·실린더 선택 중에는 전환할 수 없다.

## 기존 정의 확인

| 표시 이름 | 내부 식별자 | 기존 효과 |
| --- | --- | --- |
| 초탄 | `opening` | 첫 장전 칸이면 화력 +3 |
| 종결탄 | `finisher` | 마지막 장전 칸이면 화력 +4 |
| 경량장전탄 | `lightLoad` | 빈 칸마다 화력 +2 |
| 평두탄 | `flatNose` | 충격 +4 |
| 절개탄 | `wounding` | 화력 2, 상처 +3 |
| 고압탄 | `plusP` | 화력 8, 반동 3 |
| 저반동탄 | `lowRecoil` | 화력 3, 반동 없음, 사격 전 반동 2 회복 |
| 연계탄 | `relay` | 바로 다음 탄 화력 +4 |

요청된 네 권총과 모든 탄약이 이미 존재하며 정의가 불명확한 항목은 없다. 탄약 효과·무기 수치·탄창 용량·적 행동·진행 구조를 변경하지 않았다. 현재 게임은 기존 체력 10000의 훈련 표적 구간을 사용한다. 처치와 미발사 경계는 낮은 체력의 로컬 검증 표적과 자동 테스트로 확인한다.

검증 결과와 실제 화면은 [검증 기록](validation/game-modes/검증기록.md)에 정리한다.
