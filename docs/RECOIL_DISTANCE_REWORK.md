# 반동·거리 전투 개편 기록

## 결과

반동의 직접 피해 감소를 제거하고 각 사격 후 자세를 회복하는 동안의 추가 접근으로 바꿨다. 독립 명중 보정 능력치는 데이터·공식·화면·적 방해·테스트에서 제거했다. 거리 손실은 서비스 .45 기준 근거리 0%, 중거리 10%, 원거리 25%이며 직접 화력에 한 번 적용한 뒤 `.5 올림 최근접 반올림`으로 정수화한다.

정규화된 화력·체력·방어·방어 파괴·충격·상태 수치는 유지했다.

## 반동 공식과 계수

```text
발사 후 누적 반동 = 발사 전 누적 반동 + 이번 탄의 유효 반동
재조준 추가 접근 = 적의 평소 한 턴 이동 × 0.01 × 발사 후 누적 반동
```

적이 살아 있다면 마지막 탄을 포함한 모든 사격 후에 추가 접근을 적용한다. 각 추가 접근은 상태 거리와 화면 애니메이션에 즉시 반영되고, 탄창 뒤 적 행동의 평소 이동은 별도로 정확히 한 번만 적용한다. 처치한 탄에는 접근을 적용하지 않는다. 누적 반동은 `resolveSequence`의 지역 변수라 새 탄창 발사 시퀀스마다 0으로 초기화된다.

재조준 표시 시간은 `170ms + 누적 반동 × 45ms`다. 총이 목표로 다시 가라앉는 동안 좀비가 작은 거리만큼 전진한다.

### 계수 선택 근거

일반 감염체의 평소 이동은 2m다. 마지막 탄까지 0.015를 그대로 쓰면 6발 표준탄의 접근이 0.63m로 커져 기존 25% 안전선을 넘었다. 0.01을 적용하면 4발은 `0.02 + 0.04 + 0.06 + 0.08 = 0.20m`, 6발은 0.42m다. 모든 사격의 접근을 보존하면서도 기존 전체 위험도와 접촉 행동 수를 유지한다.

| 구성 | 일반 이동 | 탄창 중 반동 접근 | 한 사이클 합계 | 기준 접촉 | 반동 포함 접촉 |
|---|---:|---:|---:|---:|---:|
| 저반동 4발 | 2.00m | 0.00m | 2.00m | 4행동 | 4행동 |
| 표준탄 4발 | 2.00m | 0.20m | 2.20m | 4행동 | 4행동 |
| 표준탄 6발 | 2.00m | 0.42m | 2.42m | 4행동 | 4행동 |
| 고압탄 4발 | 2.00m | 0.40m | 2.40m | 4행동 | 4행동 |
| 고압탄 4발 + 이중 포트/G10 | 2.00m | 0.20m | 2.20m | 4행동 | 4행동 |
| 고압탄 6발 | 2.00m | 0.84m | 2.84m | 4행동 | 3행동 |

현재 저장소의 대표 일반 감염체 기준 접촉 시간은 요청에서 가정한 약 3행동이 아니라 실제 데이터상 4행동이다. 보통 시작 탄창 4발과 확장 6발 표준탄 모두 이 4행동을 유지한다. 고반동 6발 극단 구성만 3행동으로 줄어 위험 증가를 분명히 만든다.

## 거리와 반올림

서비스 .45의 모든 탄은 동일한 기본 프로필 0%·10%·25%를 사용한다. 매치탄은 10%p, 고시인성 가늠쇠는 중거리 10%p, 반사 조준기는 중·원거리 10%p를 완화한다. 여러 소수 배율을 쌓지 않고 퍼센트포인트를 한 번 합산한 뒤 하나의 거리 배율만 적용한다.

| 탄약 | 직접 화력 | 근거리 | 중거리 계산 → 결과 | 원거리 계산 → 결과 |
|---|---:|---:|---:|---:|
| 표준탄 | 4 | 4 | 3.6 → 4 | 3.0 → 3 |
| 확장탄 | 6 | 6 | 5.4 → 5 | 4.5 → 5 |
| 철갑탄 | 3 | 3 | 2.7 → 3 | 2.25 → 2 |
| 와드커터탄 | 3 | 3 | 2.7 → 3 | 2.25 → 2 |
| 평두탄 | 4 | 4 | 3.6 → 4 | 3.0 → 3 |
| 고압탄 | 8 | 8 | 7.2 → 7 | 6.0 → 6 |
| 저소음탄 | 3 | 3 | 2.7 → 3 | 2.25 → 2 |
| 본디드탄 | 5 | 5 | 4.5 → 5 | 3.75 → 4 |
| 매치탄 | 3 | 3 | 3.0 → 3 | 2.55 → 3 |

반올림 후보 비교에서 내림은 중거리 화력 2~5를 모두 1씩 낮춰 10%보다 훨씬 가혹했다. 올림은 중거리 화력 2~8에서 손실이 전혀 없어 거리 상태가 무의미했다. 최근접 반올림은 중거리 화력 2~5에는 완만하고 6~8에는 1 손실을 만들며, 원거리 25%에서는 화력 2~8이 `2/2/3/4/5/5/6`이 되어 저화력을 과도하게 누르지 않으면서 고화력에도 손실을 남긴다.

## 폐기 효과 이전

| 콘텐츠 | 이전 효과 | 현재 효과 |
|---|---|---|
| 와드커터탄 | 명중 보정 +1 | 보정 삭제, 반동 0 선행탄 정체성 유지 |
| 고압탄 | 명중 보정 -1 | 보정 삭제, 반동 2의 재조준 위험으로 비용 통합 |
| 저소음탄 | 명중 보정 +1 | 보정 삭제, 반동 0 정체성 유지 |
| 매치탄 | 명중 보정 +2 | 거리 손실 10%p 완화, 반동 0 |
| 휴면 압력·중량·빙결·서약·각인탄 | 양수/음수 명중 보정 | 보정 삭제, 각 탄의 충격·상태·특수 적·회수 정체성 유지 |
| 소형/이중 포트 보정기 | 보정 +1, 일부 탄약 페널티 감소 | 반동 20%/35% 감소 |
| 고시인성/반사 조준기 | 보정 +1, 일부 중거리 완화 | 중거리 제거 / 중거리 제거·원거리 10%p 완화 |
| 소형 레이저/레이저·라이트 | 근거리·최근접 보정 | 조건부 반동 15% / 20%+10% 감소 |
| 고무/G10 손잡이 | 보정 +1 또는 탄약 페널티 감소 | 반동 15%/25% 감소 |
| 지반 파쇄체 | 2턴 보정 -2 | 2턴 탄약 반동 +50% |

무기와 탄약의 관련 필드, 플레이어 상태, 장착물 수정자 종류, 피해 내역, UI 수치 행은 모두 삭제했다. 어떤 효과도 일반 화력 보너스로 자동 변환하지 않았다.

## 재현 검증

`src/simulation/RecoilDistanceAudit.test.ts`는 6개 탄창 구성 × 일반·장갑·거대 적, 활성 탄약 9종 × 세 거리, 화력 2~8의 내림·올림·최근접 반올림을 실제 데이터로 출력한다. 전투 테스트는 방어 파괴, 방어 흡수, 화상 2회, 충격, 냉기·전하·침식, 봉쇄, 초음파, 돌파 중단을 회귀 검증한다.
