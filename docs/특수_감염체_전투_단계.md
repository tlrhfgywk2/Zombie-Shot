# 특수 감염체와 전투 단계

## 구현 구조

기존 탄창·행동 기회를 그대로 사용한다. 단독전은 탄창을 순서대로 발사하고, 다수전은 한 발씩 재조준하되 탄창 종료 후 예고한 한 마리만 행동한다. 처치된 행동자의 기회를 다른 적에게 넘기지 않는다. 별도 시간축, 대기 버튼, 강제 생존 구간은 추가하지 않았다.

- `enemyBehaviorDefinitions.ts`: 유형별 시작 단계, 다음 단계, 자기 행동 기회 수, 직접 화력 배율, 이동량, 색상과 방어 붕괴 조건.
- `EnemyBehavior.ts`: 상태 생성·복사에 사용할 독립 데이터, 단계 전환, 방어 압력, 실제 활성 장착물 선택과 임시 교란.
- `CombatResolver.ts`: 기존 명중 계산의 마지막 직접 화력에만 단계 배율 적용. 실제 행동 기회에서 충격·사거리·단계 전환을 판정한다.
- `EnemyBehaviorView.ts`: 현재 단계·배율·붕괴 진행·교란 대상과 준비 시간을 표시한다. 다수전의 다음 위협 시점은 자기 행동 순서와 활성 적 수로 계산한다.

각 적의 `behavior`에 단계, 남은 자기 행동 기회, 방어 압력·명중 수, 전환 원인을 저장한다. 예측 계산과 좀비 스냅샷은 중첩 상태를 복사한다. 대기하는 적의 단계와 상태 수명은 다른 적의 행동으로 줄어들지 않는다.

사격 중에는 방어 압력만 누적한다. 세 번째 명중으로 붕괴가 예약되어도 나머지 탄은 계속 기존 60% 배율을 사용한다. 실제 붕괴와 회복 전환은 해당 적의 행동 경계에서만 발생한다. 새 방어 단계는 다음 사격을 확정하기 전에 화면에 표시된다.

## 실험 수치

새 세 유형의 체력은 모두 32다. 기존 적 체력·탄약 수치·상태 임계치는 변경하지 않았다.

| 유형 | 단계와 다음 행동 | 직접 화력 | 이동 |
| --- | --- | ---: | ---: |
| 방패 돌진체 | 방어 → 돌진 준비 | 60% | 방어 접근 1.5 m |
| 방패 돌진체 | 돌진 준비 → 회복 | 140% | 돌진 5 m |
| 방패 돌진체 | 회복 → 방어 | 130% | 0 |
| 광란 감염체 | 광란 준비 → 회복 | 150% | 돌격 3.5 m |
| 광란 감염체 | 회복 → 광란 준비 | 125% | 0 |
| 장비 교란체 | 교란 준비 → 교란 직전 | 100% | 준비 접근 1.7 m |
| 장비 교란체 | 교란 직전 → 회복 | 120% | 교란 사거리 8 m |
| 장비 교란체 | 회복 → 교란 준비 | 120% | 0 |

각 단계는 기본적으로 자기 행동 기회 한 번이다. 방패는 7 m, 광란은 4.5 m, 교란체는 7 m에서 시작한다. 방패·광란의 돌격은 이동 행동이며, 근접에 도달한 그 기회에 추가 치명 공격을 하지 않는다. 이후 회복 기회도 제공한다. 회복 종료 뒤 1 m 미만이라면 다음 치명 공격을 명확히 예고한다. 예고된 치명 공격이 최종 거리에서 연결되면 기존처럼 즉사한다.

단계 배율은 거리·반동·상처 취약을 적용한 직접 화력에 곱하고 반올림한다. 원래 양수인 직접 화력은 방어만으로 0이 되지 않는다. 즉시 화상·기폭·파열 피해와 상처·화상·폭발·충격 누적은 기존 계산을 유지한다. 화력 상세에는 적 자세에 의한 증감을 별도 표시한다.

## 중단과 회피

| 행동 | 기본 충격 임계치 |
| --- | ---: |
| 방어 접근·교란 준비·회복 | 4 |
| 방패 돌진·장비 교란 | 6 |
| 광란 돌격 | 7 |
| 근접 치명 공격 | 기존 8 |

새 유형의 충격 저항은 0이다. 충격 중단은 이동·공격·교란을 모두 취소하고 회복으로 전환한다. 이미 회복 중인 행동을 중단하면 다음 단계로 진행한다. 기존처럼 임계치만 소비하고 초과 충격은 보존한다. 취약은 중단에도 자기 행동 기회를 소비하며, 점화는 충격 중단 때 유지된다.

방패는 방어 중 압력 18 이상 **또는** 유효 피해 명중 3회로 다음 행동이 붕괴한다. 압력은 방어 감쇠 직전 직접 화력과 즉시 화상·기폭·파열 화력의 합이다. 명중 중 배율 변경은 없다. 붕괴가 예약되면 예고에 행동 취소를 표시하며, 행동 경계에서 이동 없이 회복한다. 이미 붕괴한 행동에는 충격을 추가 소비하지 않는다. 방어 파괴는 처치의 필수 조건이 아니다.

후퇴탄은 기존처럼 플레이어와 모든 적 사이의 거리를 늘린다. 방패 준비 뒤 후퇴탄 한 발은 돌진 결과를 0.5 m에서 2.5 m로 바꾸지만 돌진 자체는 실행된다. 강타탄은 돌진 전체를 중단한다. 두 선택은 서로 다른 거리·회복 주기를 만든다.

점화는 새 돌진·광란 돌격·장비 교란을 기존 일반 접근으로 대체하고 회복으로 전환한다. 예고된 근접 치명 공격은 점화만으로 막지 못한다. 후퇴로 치명 공격이나 교란 사거리를 벗어나면 접근만 하며 실행 단계는 보류한다.

## 임시 장비 교란

처음 등장할 때부터 준비 단계와 교란까지 남은 턴, 실제 대상 슬롯·지속시간을 표시한다. 교란 준비 단계가 끝난 다음 자기 기회에 발동한다. 근접 치명 공격이 우선인 경우 미래 교란 예고를 숨겨 현재 공격과 혼동하지 않게 한다.

현재 무기에 호환되고 실제 활성화된 장착물 중 탄창 슬롯을 제외하여 고정 순서로 하나를 선택한다. 1턴 비활성화하며 제거·파괴·소유권 변경은 없다. 대상이 없거나 탄창 장착물만 있으면 기존 거리 교란을 1단계, 1턴 적용한다고 사전에 알린다. 더 긴 기존 거리 교란의 강도·기간은 줄이지 않는다.

효과는 다음 탄창의 전역 적 행동 기회가 끝날 때 복구된다. 다수전에서 다른 적이 행동하거나 예정 행동자가 처치되어도 한 번만 경과한다. 탄창 용량은 교란하지 않으며 조우 종료 시 기존 효과 초기화와 함께 정리된다.

## 탄약·배치 호환

특수탄은 실제 발사한 수량만 조우 안에서 소진되고, 전체 조우 종료 후 복구한다. 표적 교체·탄창 배열·무기 특성·미발사 탄 처리는 유지한다. 새 탄약 계열, 전역 방어구, 명중률, 플레이어 체력, 손·팔 모델은 추가하지 않았다.

프리 모드의 기존 1~3조우 뒤에 세 단독 실험 조우와 세 다수 실험 경로를 추가했다. 최대 활성 적 2마리와 교대 규칙은 유지한다. 탐험의 지도·생성 풀·상점·보상은 변경하지 않았으며 새 유형을 탐험 전투 구성에 전달하는 경로도 호환된다.

## 검증과 후속 과제

수치 비교, 재현 명령과 화면은 [검증 기록](validation/special-infected/검증기록.md)에 정리했다. 표준탄만 사용하는 네 무기와 세 단독·세 다수 조우, 시작 거리 2 m 불이익을 포함한 48개 조합에서 피할 수 없는 사망은 발견하지 못했다. 이는 전체 탄약 배열·모든 거리 상태의 완전 탐색을 뜻하지 않는다.

실험 배율과 방어 압력은 구성 데이터에서 조정할 수 있다. 실제 플레이 자료를 바탕으로 무기별 효율을 추가 조정하고, 새 유형을 탐험 생성 풀에 편입하는 작업은 별도로 판단한다. 모델은 기존 감염체와 고리 색상·자세를 재사용하며 전용 방패 모델과 신규 공격 애니메이션은 범위 밖이다.
