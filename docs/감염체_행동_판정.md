# 감염체 행동의 충격 중단과 후퇴 지연

## 기존 구현과 변경 범위

기존에는 사격 후 거리에서 행동을 다시 선택했다. 근접은 거리 0 m의 치명 공격 하나였고, 원거리 능력에는 사거리가 없었다. 훈련 표적은 접근·오염 투척·지반 충격·초음파 공명을 섞은 묶음을 순서대로 사용했다. 일반 특수 적은 자신에게 정의된 능력과 기존 재사용 대기만 사용했다.

이제 사격 첫 발 직전에 예고를 고정하고, 모든 발의 피해·충격·이동을 적용한 최종 상태에서 판정한다. 일반 피해탄이나 사격 중 이동이 새 행동을 뽑지 않는다. 한 적 행동 기회에는 접근과 별도 공격을 함께 수행하지 않는다.

별도 강근접 행동은 기획이 없어 추가하지 않았다. 기존 치명 공격과 적별 충격 저항을 유지한다. 치명 공격 기본 임계치는 8이며 일반·강인한·거대 감염체의 실제 임계치는 각각 8·9·10이다. 탄약·반동·상처·폭발·화상·장착물 효과와 기존 거리 이동 제한을 유지하며 새 후퇴 제한은 도입하지 않는다.

## 최종 판정 순서

1. 적이 사망했다면 행동과 상태 예약을 종료한다.
2. 예고된 행동의 충격 임계치에 도달했다면 행동을 무효화한다. 이동은 이미 적용되어도 적은 접근하지 않는다. 임계치만 소비하며 초과 충격은 남긴다.
3. 충격 중단이 없다면 최종 거리에서 예고 행동의 사거리를 확인한다.
4. 사거리 안이면 원래 행동을 수행한다. 후퇴 자체만으로 원거리 능력을 취소하지 않는다.
5. 사거리 밖이면 접근만 수행하고 원래 행동을 보류한다.
6. 적 행동 기회가 끝난 뒤 다음 예고를 한 번 선택한다.

| 예고와 원인 | 이번 적 행동 | 다음 예고·회복 |
| --- | --- | --- |
| 치명 공격 + 후퇴로 거리 0 m 이탈 | 접근 | 아직 멀면 계속 접근, 0 m에 도달하면 같은 치명 공격 |
| 치명 공격 + 충격 | 아무 행동도 하지 않음 | 회복 접근 한 번을 강제한 뒤 같은 치명 공격. 이미 0 m여도 접근 기회를 소비 |
| 원거리 능력 + 사거리 안 후퇴 | 원래 능력 | 기존 선택 규칙 |
| 원거리 능력 + 사거리 밖 후퇴 | 접근 | 보류 능력이 유효하면 재예고, 아직 멀면 접근만 예고 |
| 원거리 능력 + 충격 | 아무 행동도 하지 않음 | 바로 다음 기회에서 해당 능력 하나만 제외. 다른 능력·접근·근접 공격은 가능 |
| 후퇴와 충격 동시 발생 | 아무 행동도 하지 않음 | 충격 전용 규칙 적용. 원거리 보류 상태 정리 |

회복 접근도 충격으로 중단하면 수행된 것으로 계산하지 않으며, 실제 접근 기회를 수행할 때까지 회복 상태를 유지한다.

## 능력별 잠정 사거리

최대 사거리는 `src/data/enemyActionDefinitions.ts`의 `ENEMY_RANGED_ACTIONS`에 능력별 데이터로 저장한다. 최솟값은 근접 우선권에 따른 거리 0 m 초과이며 최댓값은 포함한다. 기존 거리 구간을 참고한 임시 밸런스 값으로, 향후 능력별로 독립 조정할 수 있다.

| 능력 | 최대 사거리 | 초기값의 기준 | 기존 효과 |
| --- | --- | --- | --- |
| 오염 투척 | 8 m | 중거리 경계 | 장착물 슬롯 하나 2턴 봉쇄 |
| 지반 충격 | 4 m | 근거리 경계 | 반동에 따른 화력 감소 2턴 강화 |
| 초음파 공명 | 12 m | 현재 전투의 최대 거리 | 유효 거리 단계 2턴 악화 |

새로 선택하는 예고는 현재 거리에서 유효해야 한다. 훈련 행동 묶음에서 사거리 밖인 능력은 제거하지 않고 건너뛰며, 첫 유효 행동을 선택한다. 모두 불가능하면 접근한다. 기존 특수 적은 자신의 능력에 사거리가 닿지 않으면 접근한다. 행동을 섞는 방식과 적별 능력 제한·기존 재사용 대기를 유지한다.

사격 도중 사거리를 벗어나면 이미 고정된 예고는 유지하되 UI에서 지연 접근을 표시한다. 이후 접근 중에는 접근만 예고하고 보류 능력의 사거리를 툴팁에 표시한다.

## 상태 저장과 경계 사례

`EnemyState`에 다음 원시값을 선택 필드로 저장한다. 새 적 생성 시 예약이 없으므로 재시작과 조우 전환에 전역 상태가 남지 않는다.

| 필드 | 역할 |
| --- | --- |
| `telegraphedAction` | 현재 기회의 원래 예고. 사격 시작 시 고정하고 기회 종료 시 갱신 |
| `delayedAction` | 후퇴로 보류된 행동 또는 충격 뒤 회복할 근접 공격 |
| `meleeRecovery` | 실제 접근 한 번을 아직 수행해야 하는 근접 회복 |
| `excludedAction` | 바로 다음 기회에서만 재선택할 수 없는 특정 원거리 능력 |

행동 결과는 원래 `selectedAction`, 실제 `executedAction`, 그리고 `resolution`으로 구별한다. `resolution`은 정상·충격 무효화·후퇴 지연·근접 회복·사망을 구별한다. 무효화와 사망에는 실행 행동이 없다.

보류 능력 재시도는 현재 적이 지원하는 능력인지도 확인한다. 지원하지 않는 오래된 보류 능력은 폐기한다. 일시적인 사거리 부족은 접근하면서 보존하고, 실제로 능력을 수행할 때만 기존 훈련 묶음과 재사용 대기를 소비한다. 원거리 보류 중 거리 0 m에 도달하면 보류를 즉시 정리하고 치명 공격을 다음에 예고한다. 접근 뒤 같은 기회에 공격하지 않는다. 사격 전 예고가 접근·원거리였는데 전진으로 근접에 들어간 경우도 예고되지 않은 치명 공격을 즉시 추가하지 않는다.

충격으로 원거리 행동을 중단하면 보류를 폐기하고 해당 능력만 다음 기회에서 제외한다. 훈련 묶음이 다시 섞이며 같은 능력으로 시작하더라도 제외를 지킨다. 다음 기회가 끝나면 제외가 해제된다. 다른 능력이나 사거리에 더 유리한 행동이 선택될 수 있으며 별도 다중 턴 금지는 없다.

여러 후퇴·전진은 기존 탄약 순서대로 적용하고 최종 거리만 행동 판정에 사용한다. 사망 뒤 탄은 기존대로 미발사 처리한다. 취약은 중단에도 턴을 소비하고, 점화는 기존대로 실제 행동을 수행할 때 소비한다. 점화가 원거리 능력을 봉쇄해 접근으로 바꾸는 기존 규칙도 유지한다.

## 표시와 검증

기존 ‘다음 행동’ 영역에서 지연과 회복 접근을 표시한다. 적 행동 단계에는 같은 영역을 ‘행동 결과’로 바꿔 충격 중단·지연 접근·회복을 보여 준 뒤 다음 예고로 돌아간다. 특수 능력의 기존 420 ms 대기와 일반 350 ms 대기를 유지한다. 피해 미리보기는 추가하지 않았다.

자동 테스트는 근접 후퇴·충격·0 m 회복, 적별 높은 임계치, 능력별 사거리, 장거리 유효 행동, 원거리 재시도·즉시 재선택 제외, 혼합 이동·동시 충격, 미지원 보류·근접 우선권, 사망·새 적 초기화를 확인한다. 무작위 행동 묶음은 주입한 고정 난수로 재현한다. 강근접 행동에 대한 테스트는 사용자 요청에 따라 추가하지 않았다.

렌더링 검증 기록과 화면은 `docs/validation/infected-actions/검증기록.md`에 둔다.
