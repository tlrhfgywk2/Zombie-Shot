# 동굴 탐험 프로토타입

## 진행 구조

모드 선택 → 권총 선택 → 동굴 입구의 정보 장비 선택 → 현재 갈림길 → 조우 → 보상 또는 선택 → 다음 갈림길 순서다. 전역 경로 지도는 표시하지 않는다. 현재 갈림길의 왼쪽·오른쪽만 보여주며, 정보를 얻기 전에는 목적지를 알 수 없다.

| 구간 | 생성되는 조우 |
| --- | --- |
| 1 | 일반 감염체 |
| 2 | 서로 다른 이벤트 두 가지 |
| 3 | 일반 또는 강인한 감염체 |
| 4 | 감염체 상인 두 가지 재고 중 하나 |
| 5 | 한 길은 강인한·질주·거대 감염체, 다른 길은 이벤트 또는 추가 상인 |
| 6 | 강인한·질주·거대 감염체 |
| 7 | 서로 다른 이벤트 두 가지 |
| 8 | 공명 비명체 또는 지반 파쇄체 |
| 9 | 동굴 출구 |

각 구간에는 두 경로가 있고 출구에는 한 경로만 있다. 경로를 선택하면 선택하지 않은 길로 돌아갈 수 없다. 런 생성 시 문자열 시드로 모든 목적지·감염체·이벤트·보상·상인 재고를 미리 확정한다. 선택 이후 추첨하지 않는다. 같은 시드를 넣으면 동일한 경로 묶음과 전투 실린더 회전 난수를 재현할 수 있다. 예: `?seed=browser-101`. 명시적인 시드가 없으면 새 런마다 새 시드를 만든다.

`ExplorationRun`은 경로 생성·정보·인지·회피·진행을 담당하고, `Game`은 기존 전투와 연결하며 이벤트·거래를 제어한다. `GameStateMachine`의 `EXPLORATION` 상태에서만 경로·거래·이벤트 입력을 받는다. `GameUI`는 같은 탐험 화면 모델을 데스크톱과 세로 화면에 렌더링한다. 탐험에서는 전투 모델을 숨기고 가벼운 동굴 실루엣을 사용한다. 전투 진입 시 기존 Three.js 장전·사격·적 연출을 그대로 사용한다.

## 정보 도구

| 도구 | 공개하는 정보 | 제한 | 획득 |
| --- | --- | --- | --- |
| 진동 청음기 | 보통·빠른·무거운 생체 반응, 고른 호흡, 움직임 없음, 강한 공명·인지 교란 | 감염체의 정확한 종류나 이벤트 이름은 공개하지 않음 | 입구에서 무료 선택, 관측선 이벤트에서 특수탄 1발, 상인에게 특수탄 1발 |
| 자외선 등 | 자연 동굴, 오래된 시설, 거래 표식, 바깥의 빛 | 감염체 종류와 이벤트 이름은 공개하지 않음 | 입구에서 무료 선택, 관측선 이벤트에서 특수탄 1발, 상인에게 특수탄 1발 |
| 찢어진 측량도 | 선택한 현재 경로의 정확한 목적지 | 런당 2회, 이미 확인한 길은 다시 차감하지 않음, 재구매 불가 | 관측선 이벤트 또는 상인에게 특수탄 1발 |

입구에서 청음기와 자외선 등 중 하나를 반드시 챙긴다. 두 도구는 획득 시 인지 +1을 준다. 측량도는 인지를 올리지 않는다. 초반부터 일부 정보를 얻으며, 상인이나 이벤트로 다른 종류의 정보를 추가할 수 있다. 중간의 혼합 갈림길에서는 생체 반응과 시설·거래 표식으로 전투 위험과 성장 기회를 비교한다. 생체 반응의 강도는 일반 조우의 선택에도 도움이 된다.

## 이벤트

선택은 한 번만 적용한다. 모든 이벤트에 아무것도 얻거나 지불하지 않고 지나가는 선택이 있다. 비용을 지불할 수 없거나 소유·휴대 제한에 걸린 선택은 비활성화된다.

| 이벤트 | 선택과 효과 |
| --- | --- |
| 물이 스미는 보급함 | 평두탄 2발을 얻고 다음 실제 전투 시작 거리 −2m, 또는 흔적을 살펴 인지 +1 |
| 끊어진 관측선 | 선택한 특수탄 1발을 영구 지불해 측량도 획득, 또는 아직 없는 청음기·자외선 등 획득 |
| 탄피가 쌓인 제단 | 선택한 특수탄 1발을 영구 지불해 중공탄 2발, 또는 휴대 한도 +2 |
| 숨 쉬는 균사 둥지 | 맥박을 익혀 인지 +1, 또는 텍스처 손잡이를 얻고 다음 실제 전투 시작 거리 −2m |

거리 위험은 다음 실제 전투 한 번에 적용하며 시작 거리는 최소 3m다. 회피와 비전투 조우로 위험을 지울 수 없다. 이벤트 위험이 겹치면 중첩하지 않고 −2m를 유지한다. 부착물은 획득만 하며 직접 장착해야 효과를 얻는다.

## 감염체 상인

지불할 특수탄 종류를 고른 뒤 거래한다. 여러 종류를 섞어 지불하지는 않는다. 표준탄은 무제한이므로 결제에서 제외한다. 지불 수량보다 소유량이 적으면 거래할 수 없다. 모든 거래는 원자적으로 검증하며 실패 시 재고를 바꾸지 않는다.

| 상품 | 비용 | 효과 |
| --- | --- | --- |
| 찢어진 측량도 | 선택한 특수탄 1발 | 목적지 공개 2회 |
| 진동 청음기 | 선택한 특수탄 1발 | 생체·교란 감지, 인지 +1 |
| 자외선 등 | 선택한 특수탄 1발 | 시설·거래·출구 식별, 인지 +1 |
| 밀봉 탄약 묶음 | 선택한 특수탄 1발 | 해당 경로에 미리 생성한 특수탄 3발 |
| 회수한 부착물 | 같은 특수탄 2발 | 텍스처 손잡이·보정기·레이저 조준기 중 미리 생성한 하나 |
| 탄약 주머니 | 선택한 특수탄 1발 | 휴대 한도 +4 |

각 상품은 해당 상인에게서 한 번만 구매할 수 있다. 이미 보유한 장비·부착물을 다시 구매할 수 없다. 결제한 탄은 소유량에서 영구 이전되므로 조우 종료 복구로 되돌아오지 않는다. 탄약을 모두 지불해도 표준탄으로 계속 싸울 수 있으며 상인을 언제든 떠날 수 있다. 휴대 한도가 부족하면 탄약 묶음 구매를 막는다.

## 전투 보상과 회피

일반·위험 조우 처치 시 미리 생성된 서로 다른 특수탄 두 종류 중 1발을 선택한다. 후보는 중공탄·고압탄·저반동탄·절개탄·열상탄·강타탄·후퇴탄·돌진탄·연계탄·초탄·종결탄이다. 휴대 한도가 찼으면 보상을 포기하고 진행할 수 있다. 위험 조우는 텍스처 손잡이도 지급한다. 이미 보유했다면 중복하지 않는다.

인지는 0~3이다. 처치 시 +1, 청음기·자외선 등 획득 시 각각 +1, 일부 이벤트에서 +1이다. 일반·강인한·거대 감염체는 인지 2 이상, 질주 감염체는 3 이상일 때 전투 전에 회피할 수 있다. 회피는 인지 1을 지불하고 특수탄·부착물·처치 인지 증가를 모두 포기한다. 공명 비명체와 지반 파쇄체는 인지를 교란하므로 회피할 수 없다.

전투의 탄약 효과·발사 순서·거리 판정·반동·상태 효과·적 행동·즉사는 변경하지 않았다. 탐험은 훈련 표적 대신 기존 실제 감염체 정의를 사용한다. 발사 소모는 조우 종료 시 돌아오지만 거래 비용은 돌아오지 않는다.

## 밸런스 가정과 한계

기본 런은 운 때문에 막히지 않도록 여유 있게 설계했다. 네 권총 각각 40개 시드의 필수 전투를 표준탄만 채운 탄창으로 완료했다. 즉, 특수탄을 지불해도 진행 자체가 불가능해지지 않는다. 특수탄 배열·부착물은 처리 효율과 위험 선택의 여유를 늘리고, 회피는 즉사 위험을 줄이는 대신 성장을 포기한다.

프로토타입은 9개 구간·4개 이벤트 종류·1~2회 상인 방문·4~5회 전투의 짧은 구조다. 회피하면 실제 전투 수는 줄어든다. 전역 지도, 저장·이어하기, 런 간 성장, 대규모 동굴 이동이나 상인 전용 3D 자산은 없다. 경로의 조우 범주는 구간별로 제한되므로 반복 플레이에서 큰 흐름을 익힐 수 있다. 다음 단계에서는 실제 플레이 피드백을 바탕으로 조우 범주 혼합, 정보 단서의 세분화, 특수탄 배열 선택에 따른 완주 난도를 조정할 수 있다.

자동·브라우저 검증의 범위는 [검증 기록](validation/exploration/검증기록.md)을 참고한다.
