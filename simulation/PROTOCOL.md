# 고정 평가 규약 v1.0

이 파일과 protocol.json은 후보 규칙 구현 전에 작성한다. baseline.json은 원본 CombatResolver를 메모리에서 번들해 실행한 결과다. 시나리오, 시드, HP, 성공 조건은 후보 실패를 이유로 수정하지 않는다. 탄약 규칙·보급·업그레이드 변경은 버전별 후보로 기록한다.

- 탐색 200개 시드(11001–11200), 마지막 후보 확정 후 처음 실행할 홀드아웃 100개(830001–830100). 시드당 모든 적·거리·전략을 교차한다. 시드별 보상 테이프는 전략 및 빌드에 공통이다. 적은 현행 7종의 원래 HP/행동/속도/임계치를 사용하고, 별도 스트레스에서 HP 2배·4배, 상처/화상/충격 저항 변화와 장기 소모전을 보고한다. 원래 적을 약화하지 않는다.
- 초반 1, 중반 9, 후반 18 전투 전 상태. 현행 탐험 9노드는 후반 콘텐츠를 구현하지 않았으므로 18전투 보급 일정은 **제안된 진행 의존성**이다. 각 승리 뒤 특수탄 3택1·1발, 소지 배분 상한14, 전투 내 유한 소모, 다음 조우 재보급은 Player.startStage와 동일하다. 시작은 P220의 실제 3발 배분. 부착물은 3승마다 현행 미소유 호환 추첨, 같은 슬롯은 하나만 사용한다. 후보의 강화 보상은 같은 승리 예산에서 별도 명시하며 비교 중 무상 지급하지 않는다.
- A: 같은 6m·무상태·HP 10억 표적에서 매 발 해결. HP 기반 탄약은 현행 상한 사용. 자연 획득 탄창 용량으로 집계하고 용량4/6/8 층화도 제공한다. 8은 현재 무기에 불가능한 확장 시험이며 통과 근거로 쓰지 않는다. 획득만 본 조건부 상한과 실제 생존 런은 구분한다.
- B: 실제 획득한 재고에서 정해진 선택기로 구성. 상호작용하는 두 종류 이상을 포함한 탄창을 규칙 기반으로 분류하고 제외 수를 공개한다. 같은 내용의 64 무작위 순서 중앙값과 순서 탐색 결과 비교. 4/6은 고유 순열 전수, 8은 예산 제한 탐색. 생존 이점은 피해 비율에 합산하지 않는다. 60%/1.25 조건은 초기 그대로다.
- C: 상처, 열 저장, 폭약 축적, 반동 전환을 네 주축으로 평가. 열·상처 및 충격·폭약 두 혼합형도 같은 예산으로 평가한다. 보상 테이프·시작 재고·강화권·부착물 기회가 같다. 개별 적/거리 셀과 전체 승률, Wilson 95% 구간, 승리 시 탄수·턴수를 제공한다. 최소 네 주축 각각 최강 승률의75%와 적어도 한 시나리오의 공동 최고 승률 또는 승리당 탄수 우위를 요구한다. 동률 최고는 분명하게 표기한다.
- D: 혼합형의 같은 탄창을 교차 규칙만 끈 반사실과 쌍 비교. 주효과는 삭제하지 않는다. 중앙 피해 이득5% 이상, C 상대 승률 조건을 함께 요구한다.
- E: 18조우를 실제 순서대로 수행하고 죽으면 종료한다. 중반까지 생존하며 최소 두 상호작용 탄종과 4발 중 최소 두 특수탄을 가진 빌드를 coherent로 판정한다. 약속된 미래 보상·사후 최적화는 금지한다. 사망/획득 실패 모두 분모에 포함한다.
- F: 동일 재고·조건에서 이론 피해만 최대화한 전략과 즉시 사망 회피를 우선한 전략 비교. 최소 한 생존 우위 및 최소 한 동률 생존에서 특수탄 절약 사례를 요구한다. 위치·충격·반동·근접/원거리·행동별로 실패도 공개한다.
- G: 모든 후보 탄약에 숫자·조건·짧은 설명·목적을 정의. 실제 샷 trace와 회귀/불변조건 테스트로 계산을 확인한다. 재미·인지 부하는 자동통과로 증명하지 않고 수동 검토 항목으로 남긴다.

피해 분위수에는 시드 단위 비모수 bootstrap 95% 구간을 제공한다. 승률은 Wilson 95%; 쌍 차이는 시드 단위 bootstrap. 홀드아웃을 보고 후보를 바꾸면 해당 시드는 탐색으로 승격하고 새 미사용 홀드아웃을 선언해야 한다. 실행 도중 임의 중단/실패는 결과와 체크포인트에 남긴다.
